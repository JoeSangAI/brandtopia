# 不正经维度的消费行为预测实验

BrandTopia 的探索性实验。先聊一个人的日常和喜好，再看看这些信息能不能帮模型猜中他会给商品打几分。[初始设计文档](初始设计/设计文档.md) 供视觉与交互评审。

当前可运行版本见 [v0.1](v0.1/README.md)。试跑可使用[虚构访谈](测试/测试访谈-四组话题与意外细节.txt)和[十件商品预测](测试/我的预测-十件商品.md)。

## 项目目录

```text
原型设计/
└── 不正经维度的消费行为预测实验/
    ├── README.md
    ├── 初始设计/
    │   └── 设计文档.md
    ├── 参考资料/
    ├── 测试/
    └── v0.1/
```

`初始设计/` 归档研究问题、初始流程和评审稿。`参考资料/` 收录网页样稿及公开论文入口。`测试/` 保存同一虚构访谈及独立预测，供原型试跑和对照。

蒸馏类比对应的论文见 [Subliminal Learning](<参考资料/Subliminal Learning - arXiv 2507.14805v1.md>)。

## 版本交付目录

开发版本直接在原型目录下按实际版本号命名，与 `初始设计/`、`参考资料/` 同级。以下以 `v0.1/` 为例。

```text
v0.1/
├── README.md
├── 设计与汇报/
│   ├── 设计文档.md
│   └── 汇报.html
└── 原型/
    └── prompts/
```

同版设计、汇报和原型使用一致的流程、规则与实现状态。版本 README 提供该版设计、汇报、原型及仓库目录入口。内置提示词以 Markdown 集中保存于 `原型/prompts/`。验收从该版 HTML 汇报打开原型入口，核对主要流程、异常恢复和实际运行版本。[仓库协作约定](../../docs/governance/contributing.md)
