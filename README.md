# Brandtopia

### 从个体认知到群体行为：探索可计算的社会演化机制

> **如果我们无法准确预测一个人的下一次选择，是否仍然能够通过理解大量个体的行为机制，预测一个群体未来的变化？**

这是 Brandtopia 想要研究的核心问题。

**[第一次来？从这里开始](START_HERE.md)** · **[阅读完整研究历程](docs/theory/research-journey.md)**

## 为什么研究这个问题？

阿西莫夫《基地》中的“心理史学”提出了一个大胆设想：单个人的行动充满偶然性，群体行为却可能呈现可计算的规律。Brandtopia 借用这一问题意识，从可以被检验的小范围开始，探索个体如何通过学习、决策与互动，生成群体变化。

市场研究能够描述许多宏观结果：品牌认知的变化、购买份额、广告效果以及价格响应。但相同的销量，也可能由不同的原因产生：一次降价带来的尝试，与长期品牌信任带来的选择，面对下一次环境变化可能走向不同的未来。

我们的目标，是找到这些结果背后的**可复用微观生成机制**，逐步检验它们能否解释、预测新情境下的群体行为。

## 核心假设

**复杂的群体行为，可能由一组相对有限、可以重复使用的微观机制生成。**

每个个体都有自己的经历、记忆、信念、偏好和行动条件。新信息进入时，内部认知可能更新；需求与行动提示出现时，个体作出选择。选择又影响环境和其他人，形成新的信息与反馈。

这一假设尚未被证实。研究中的关键问题是：当新案例不断出现，模型能否复用既有机制，还是必须不断增加特例规则？它的样本外预测能力能否随证据积累而改善？

## 一套统一的研究语言

Brandtopia 暂时以 **IPO（Input—Process—Output）** 为顶层框架：

- **Input｜信息与事件：** 广告、价格、产品体验、口碑、群体交流、环境变化。
- **Process｜认知与学习：** 个体根据已有世界模型更新信念、记忆、联想、预期与对他人的判断。
- **Output｜具体行动：** 购买、等待、放弃、讨论、推荐、传播或共同决策。

行为结果进入下一轮 Input。**B=MAP（福格行为模型）** 用于理解具体行为发生时的动机、能力与提示；它还不是经过校准的购买概率公式。

我们也在研究两个重要的工作概念：**品牌Token化**，即品牌如何形成稳定可检索、可承载意义的认知单位；**信息丰度**，即某条信息在特定群体中被掌握、感知为共同知晓，并获得进一步传播机会的程度。它们的可测定义及因果效果仍待检验。

## 研究什么？

**个体认知与学习。** 一条信息为什么改变了某个人的信念？广告重复、产品体验、朋友评价如何共同影响认知与记忆？

**社会认知与群体互动。** “我知道”和“我知道别人也知道”有什么区别？信息怎样通过讨论、模仿、协调与反馈形成群体效应？

**群体演化与因果预测。** 大量拥有不同状态的个体持续互动，会产生什么规律？如果改变广告、价格、传播结构或外部环境，结果会有什么不同？

## 怎样研究？

我们并行采用**理论研究**与**计算实验**。从现实观察提出竞争性假设，使用 Agent-Based Modeling（ABM）让不同个体在明确规则下持续行动，并用可复现的实验检验规则能否生成预期现象。

随着数据条件改善，再通过公开研究、独立的小规模行为实验、授权的真实数据及样本外检验逐步校准。

**计算模拟能够生成一种现象，不等于已经证明现实社会遵循相同机制。** 我们明确区分现实观察、理论假设、合成实验、计算核验与真实数据验证。

## 当前进展

已形成第一版理论语言、研究假设与证据分级，开始构建可运行的 ABM 引擎。首个计算基线研究的是群体内的信息传播结构，已有可复跑代码与测试。这是基础设施验证，**目前没有声称已经预测真实消费者行为或营销增量**。

技术过程、参数、具体人数与复跑命令保留在实验和模型档案中，不放在研究首页。
