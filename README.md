# Brandtopia

### 从个体认知到群体行为：探索可计算的社会演化机制

> 如果我们无法准确预测一个人的下一次选择，能否通过理解个体怎样学习、记忆、决策与互动，预测一个群体在环境变化后会如何选择？

这是 Brandtopia 想要研究的核心问题。

Brandtopia 是一项从阿西莫夫《基地》的“心理史学”获得启发的探索性研究。我们把品牌、消费与传播作为具体研究范围，希望通过理论推演、个体模拟和现实证据，逐步理解群体行为如何形成，以及广告、价格、体验和社会互动怎样改变它。

## 为什么研究这个问题？

同样的销量，可能来自不同的消费者状态：有人信任品牌，有人只接受促销价格，有人恰好在需要时想起了它。当价格恢复、广告停止或更好的替代方案出现时，这些消费者可能走向不同的选择。

这使我们关心结果背后的形成过程：消费者原本知道什么？经历了什么变化？需求出现时，他能想起哪些解决方案，又愿意花多少时间判断？这些过程怎样累积成一个市场的变化？

Brandtopia 希望找到可以反复使用的解释机制，并检验它们能否帮助我们判断：**当条件改变时，接下来会发生什么？**

## 核心假设：复杂行为，能否由有限机制生成？

**在明确的研究范围内，复杂的群体行为，可能由一组相对有限、可复用的微观机制生成。**

每个人有不同的经历、记忆、信念和行动条件。相同的信息进入不同人的认知，可能带来不同的更新；这些人又会交流、模仿、协调和相互影响。我们想知道，这些差异是否能够用少数共同机制描述，并在新案例中继续有效。

因此，模型能否逐渐收敛，是研究本身的一部分。新案例出现后，既有机制能解释多少？什么现象确实需要新机制？增加机制之后，对未见过的情境是否判断得更准？这些问题决定我们有没有前进。

## 从消费者的任务理解品牌

消费者在生活中有具体的任务：解决一个问题、照顾家人、选择礼物，或表达某种身份。品牌在其中扮演什么角色？

我们的一个工作假设是：**品牌承载被压缩的经验、联想和预期，帮助消费者把当下任务与可能的解决方案连接起来，减少搜索和判断的成本。**

这种连接会随经历变化。广告可能让品牌更容易被想起，使用体验可能改变对品质的预期，他人的评价可能影响信任。当任务改变，即使已有的品牌认知保持不变，选择也可能改变。

我们把这一方向称为“品牌Token化”：研究品牌如何成为可被提取、承载意义的认知单位。这个名称保留为工作概念，具体机制和测量方式需要逐步检验。

## 三个相连的研究问题

**个体怎样学习与选择？** 信息、体验和记忆怎样改变信念？面对不同任务、预算和时间限制，人会想起什么、比较什么、采取什么行动？

**人与人怎样相互影响？** “我知道”与“我认为别人也知道”会怎样影响信任、讨论和共同决策？我们用“信息丰度”探索信息在群体中的分布、被感知为共同知晓的程度，以及继续传播的机会。

**群体变化能否被预测？** 当拥有不同状态的个体持续互动，哪些趋势会稳定出现？改变价格、广告或传播条件后，模型能否预测新的群体倾向？

## 怎样推进这项研究？

我们让理论探索与计算实验相互推动：从具体案例提出问题，比较几种可能的解释，把关键机制写成最小模型，再观察改变条件后会产生怎样的结果。每次只增加一个有必要回答的问题。

**Agent-Based Modeling（基于个体的建模，ABM）** 是主要计算路径：用具有不同状态的虚拟个体，模拟学习、选择与互动，再汇总群体结果。起步时，个体可以只使用明确的规则与概率；模型的复杂度随研究问题增加。

我们以 **IPO（Input—Process—Output）** 组织输入、内部处理和行动，行动结果再进入下一轮输入。**B=MAP（福格行为模型）** 用于描述动机、能力和提示怎样共同促成行动。具体定义与更新规则见[理论框架](docs/theory/framework.md)。

现实证据优先从公开论文和数据中获得。当一个重要问题仍无法区分，才针对缺口设计真人研究或寻找获授权的数据合作。**模拟能生成一种现象，只能说明这套规则能够产生它；现实预测能力需要用真实观测和未参与建模的数据来检验。**

## 当前阶段

项目处于理论探索与早期计算实验阶段：已整理研究主线、保存交互演示，并建立可复跑的信息传播基线。对真实消费者选择与营销效果的预测，仍是待验证的目标。目前研究在阶段归档后暂停；具体成果、证据和恢复位置见[当前状态](docs/research/current-state.md)与[完整回顾](docs/research/2026-11-22-recap.md)。
