# Brandtopia

### 从消费者怎样理解世界，研究群体怎样作出选择

> 如果我们无法准确预测一个人的下一次选择，能否通过理解个体的学习、记忆、决策与互动，预测一群人的行为倾向？

Brandtopia 从阿西莫夫《基地》的“心理史学”获得问题意识，把研究范围落在品牌、消费与传播。我们希望找到一些可以重复使用的微观机制，让群体结果从这些机制中生成，再接受真实数据的检验。

**[研究全程回顾](docs/research/2026-11-22-recap.md)** · **[第一次参与](START_HERE.md)** · **[当前状态与恢复位置](docs/research/current-state.md)**

## 我们为什么走到这里？

同样的销量，可能来自不同的消费者状态：有人信任品牌，有人只接受促销价格，有人恰好在需要时看见了它。这些人在价格恢复、广告停止或出现替代方案时，可能作出不同的选择。仅仅把过去的销量拟合得更好，未必能解释下一次变化。

我们因此逐步把问题往前推：消费者原本知道什么？广告、体验与他人评价怎样改变这些认知？需求出现时，他能想起哪些解决方案，愿意花多少时间判断？许多个体相互影响之后，会产生什么群体变化？

研究中的一个关键转向是：**以消费者要完成的任务组织认知。** 品牌可以承载被压缩的经验和预期，帮助消费者在特定任务中找到解决方案。同一个人对品牌的认识保持不变，只换任务，也可能改变选择倾向。这已经做成了一个合成概率演示；现实中的效果仍待检验。

完整来路见[研究历程](docs/theory/research-journey.md)。

## 当前采用的结构

**IPO（Input—Process—Output）** 是顶层结构：外部信息与事件进入消费者已有的认知，经由提取、理解和学习，影响下一次行动；行动及其结果又成为新的输入。

| 环节 | 我们关心的问题 |
| --- | --- |
| 输入 | 消费者实际接触了什么？来源、时间、顺序和可见范围怎样影响理解？ |
| 处理 | 什么被记住、想起、相信或重新解释？当下任务和思考成本怎样影响判断？ |
| 输出 | 在动机、能力和提示条件下，选择购买、等待、放弃、讨论还是推荐？ |
| 反馈与互动 | 体验如何更新信念？“别人也知道”如何改变传播与协调？ |

**B=MAP** 用于理解行动发生的条件。**痕迹—本体—规则** 用于组织事件、状态和更新过程。**品牌Token化** 与 **信息丰度** 保留为工作概念，其测量方式和适用范围仍在研究中。参见[框架](docs/theory/framework.md)与[术语](docs/theory/glossary.md)。

## 我们怎样判断研究有没有进步？

核心假设是：**在明确的研究范围内，复杂行为可能由相对有限、可复用的机制生成。** 每增加一种机制，都应说明它解决了什么旧模型无法回答的问题，以及什么观察会使我们放弃它。

我们区分三件事：规则能否说清、代码是否正确执行、现实是否支持这套规则。模拟次数增加只能帮助计算，不能自动消除错误假设。已有结果与被修正的判断分别保存在[证据与局限](docs/evidence/claims-and-limitations.md)和[纠偏记录](docs/evidence/corrections.md)。
