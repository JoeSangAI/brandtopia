## 下次从这里继续

恢复研究时，首选任务是：

> 找出公开实验里，同一个决策条件下，人们有 2 秒和只有 1 秒时，选择惯常动作的比例分别是多少。

使用 Lai 与 Gershman（2024）的 [论文](https://journals.plos.org/ploscompbiol/article?id=10.1371/journal.pcbi.1012057)和[公开资料仓库](https://github.com/lucylai96/simplepolicies)。只复算 Task 3 中一个对照：在惯常动作并非最优的状态里，时间缩短是否增加它被选择的比例。

下一次工作的完成标准：

1. 找到对应数据字段和分析代码，确认样本、试次、时间条件及排除口径。
2. 重现这一个比较，记录人数、有效试次数、比例与不确定性；以参与者为重复观测单位处理，不能把全部试次当独立样本。
3. 用一张简单对比图解释结果，并判断它能约束我们哪一条“思考成本”假设。

这篇论文研究任务中的动作选择。对品牌选择的迁移需要另一步检验。本项目目前**只定位了来源与公开数据入口，未下载分析、未重现论文结果、未拟合模型**。任务详见 [CHAT-21](../experiments/archive/08-human-evidence-and-replication.md)。
