## 一、我们始终在研究什么

Brandtopia 借用了心理史学的提问：**通过个体的学习、选择和互动，能否推测群体的行为倾向？**

当前研究范围是消费者、品牌、广告及相邻的社会协调情境。目标颗粒度是群体倾向，尚不追求逐人准确预测，也不声称能够预测整个社会。先用明确的小系统理解机制，再判断哪些机制值得进入更大的模型。

长期要解决的困难有三个：

1. **机制是否可以复用。** 新案例不断增加时，能否使用相对有限的更新、检索、选择和互动规则，避免为每个案例增添专门解释。
2. **数据是否足以区分解释。** 同一个结果可能来自不同机制；更多同类数据未必能够解决识别问题。
3. **模拟是否对应现实。** 程序正确执行规则，只说明规则被实现。需要独立现实证据才能判断这些规则是否值得用于预测。

理论探索和计算实验共同推进。无限算力也不能自动补上缺失的输入、错误的机制或现实验证。

## 二、研究脉络与阶段结果

### 1. 从简单参与实验开始：规则、初始状态和执行顺序

**原问题：** 三个人按各自的参加门槛行动，会发生什么？

我们讨论过停止在某个人参加之后、最终全部参加，以及达到不再变化的状态。逐渐明确：需要同时规定初始参加者、每个人能看到谁、什么时候更新，以及观察多少轮。环境规则改变后，行为结果也可能改变。

另一个已恢复版本让经历改变门槛：累计参加两轮之后，下轮更容易参加。相同的一次临时干预，在固定门槛版本中产生持续交替，在经历更新版本中最终达到全员参加。这个例子把“一次经历怎样改变后续规则”带入了研究。

**得到的认识：** 模型的完整描述包括规则、初始状态和时间安排；只报一个最终人数无法还原过程。

**记录状态：** 合成思想与交互实验。三人实验和随机顺序版本的源码已找回，可以核对所保存版本的规则；其他口头变体并非全部留存。不能把不同设定下的结果当作同一模型的矛盾。[CHAT-01 至 CHAT-03](../experiments/archive/01-thresholds-and-identification.md)

### 2. 从观察行为进入识别规则：门槛也可能被临时事件遮住

**原问题：** 看到乙参加，能否知道他的门槛是 1 还是 2？

若满足两种门槛的条件都在，两种解释会给出同样结果。让丙不参加，可以在其他条件稳定时产生不同预测；但如果乙临时有事，未参加也可能由额外原因造成。

**得到的认识：** 需要能够区分假设的干预，并明确未被控制的随机例外。单次行为通常不足以让某个机制的概率成为 100%。

**记录状态：** 合成思想实验，尚无真实参与者或真实门槛的估计。

### 3. 从个人随机性进入群体统计：相关性会改变聚合结果

**原问题：** 个人选择难以确定，是否仍可预测参加总人数？

我们讨论了独立选择、重复实验中的波动，以及公司或共同事件造成的相关行动。相同平均人数，可能对应完全不同的波动结构；标记成员来自哪家公司，有助于检查共同原因。

保存下来的演示中，十人的平均参加人数都为 9。各自独立缺席时，全员缺席的理论概率为 $0.1^{10}=10^{-10}$；集体加班时则为 10%。两者平均数相同，但不能用同一个独立模型解释。

**得到的认识：** 群体规模扩大可能帮助估计稳定的概率，但不会让共同冲击自动消失。一次偏低结果也不要求下一次必然补偿。

**记录状态：** 十人邀请和共同事件演示源码已找回。对话中脱离原配置的 1%、5% 等回答，必须回到具体演示核对分母和条件，不能登记为现实频率。[早期概率与识别记录](../experiments/archive/01-thresholds-and-identification.md)

### 4. 从既有路线进入路径依赖：改变需要重新考虑的机会

**原问题：** 如果一个人曾经选过一条通勤路线，环境变了，他会主动重选吗？

讨论转向伦敦地铁停运：被迫尝试替代方案，可能让通勤者发现原先不知道的选择。恢复通车后，人们既可能回流，也可能保留新方案。需要比较新路线替代了什么功能，例如时间、费用或便利程度。

我们提出过一个条件假设：短期通勤总量大致稳定，部分流出者被替代方案留住，原路线客流便可能逐步恢复至低于原水平的平台。更长停运时间可能改变最终留下的人数，恢复后回流速度则是另一个过程。

**已做的计算：** 用合成概率规则画恢复曲线，分开调节停运时长与回流速度。例如初始人数 1,000，停运期间每天有 10% 的剩余潜在回流者决定保留替代方案，停运两期后的回流上限为 810。这只是该设定的算术结果。

**论文带来的约束：** 伦敦研究提供了被迫尝试与路线学习的证据，但没有验证我们的指数恢复曲线、永久客流缺口或“停得越久一定越形成习惯”。研究的个人路线变化与一座车站的总客流，也不是同一指标。[实验与外部证据](../experiments/archive/02-routes-and-path-dependence.md)

**修正：** 持续上升且斜率减小的曲线，数学上是向下凹。仅凭若干恢复点推算最终为 900 或其他平台，仍依赖所选模型。多维的新证据可能比继续增加拟合项更有价值。

### 5. 竞争性假设：相同历史销量可以对应不同未来

**原问题：** 两个市场当前都卖出四件，取消优惠后是否相同？

在十人的合成例子里，可以安排两种消费者构成：优惠价时同样四人购买，恢复原价后，一组无人购买，另一组仍有四人购买。已有原价购买记录能够排除部分解释，但只有在需求、认知、产品、竞争和可得性等条件足够稳定时，才容易把差异解释为价格接受程度。

**得到的认识：** 用不同假设预测新条件的结果，比继续拟合同一条销量曲线更有识别价值。真实消费者不买某个品牌，还可能因为需求、替代方案、渠道展示或接触信息改变。

**与因果研究的关系：** 这些推演帮助我们提出干预问题和反事实问题。观察上更吻合的预测，本身还不足以证明唯一因果机制。[价格实验](../experiments/archive/03-price-advertising-and-retention.md)

### 6. 相同预算，投广告还是补贴价格？

**原问题：** 在投流费用和降价补贴之间，怎样比较消费者状态与后续购买？

我们先明确分母与观察窗口。市场总人群、目标人群、已触达人群、已决定购买者，不能混用为同一个“购买率”的分母。

合成例子让广告和促销在第一期产生相同购买人数，进一步区分广告可能带来的新知晓或评价变化，以及补贴对当期价格条件的改变。某个算例中两种方式的贡献金额都为 120；它依赖特定售价、成本和费用口径，不能换称普遍 ROI 结论。

**重要发现来自一次质疑：** 当体验强化、品牌保留和记忆保留设置为零，模型仍显示两三个人购买。检查后发现，旧规则还保留了固定基础购买者、购买者状态刷新和初始偏好。某个“原价接受率”还只影响当期输出，没有一致地流入下一期状态。

**修正：** 早期广告组长期占优，部分来自预设的不对称规则；不能据此宣称广告用户普遍比促销用户留存好。后续比较需要共用状态转移规则，再改变广告或价格输入。旧版完整模型是否已全部修好，没有足够资产可以确认。[规则与修正](../experiments/archive/03-price-advertising-and-retention.md)

### 7. 从曝光次数进入学习过程：曲线形状来自规则

**原问题：** 广告每多出现一次，效果都立即递减吗？

我们区分陌生消费者与熟悉消费者。前者可能要经历识别、建立联系等阶段，后者可能只需一次提醒。简单的“每次补上剩余差距的一部分”会产生凹曲线；设置分阶段学习，可以产生先慢后快再放缓的形状。

**已做的推演：** 两阶段学习和熟悉者唤起使用了不同的合成规则；停投后又分别讨论短期激活与较慢的关联衰减。使用体验可以成为新的强化输入。

**得到的认识：** 不必直接把曲线形状写成目标，但需要对产生曲线的过程负责。曲线“自然产生”依然以规则成立为前提。

**证据边界：** 演示中的学习率和半衰期没有实测依据。用户提到的特定研究中“若干周内达到某个曝光频次”属于待准确定位适用人群、渠道和指标的资料线索，不能写成通用门槛。[学习与停投实验](../experiments/archive/04-learning-and-memory.md)

### 8. 一次真实消费旅程，让模型接受现实复杂性检查

某餐饮品牌的去标识案例包含连续广告、数次购买、某款产品体验下降、另一新品价格偏高，以及多位家庭成员给出不同评价。

它让我们看见几个此前容易遗漏的关系：

- 广告内容本身能够形成消费前的期待与好感。
- 对产品的体验会影响产品评价，也可能外溢至品牌判断。
- “味道不错”与“值得按这个价格重复购买”可以不同。
- 同一家庭里的使用者、付款者和决策参与者未必是同一个人。
- 预期下次不买，仍不同于已经观察到停止复购。

**得到的认识：** 真实案例用来提出模型缺口，不意味着每出现一个细节就要增加一个自由参数。价格障碍也需要根据任务判断是支付能力、价值评价，还是两者共同作用。[案例记录](../experiments/archive/05-experience-and-belief.md)

### 9. 模型会不会无限膨胀？

**原问题：** 每个新案例都有新因素，所谓统一模型还有可能收敛吗？

我们把“具体事物很多”与“处理过程很多”分开。品牌、场景、体验和社会角色可以不断增加；它们是否能够复用更新、检索、选择和互动机制，需要通过跨案例预测来检验。

**形成的原则：** 状态和参数要为明确问题服务。比较更复杂的模型与简单基线；若无法改善新场景预测，或数据无法区分新增状态，就考虑合并、删减或缩小适用范围。当前没有证明存在一套覆盖所有消费行为的“大一统公式”。

Agent 模型内部仍然包含表示、规则或学习机制。换成十亿个 LLM Agent 并不会让模型假设消失，也不会让模拟结果自行成为真实观测。AI 也不能保证永不出错；规则检查、独立复核和现实验证需要各自保留。

### 10. 关系、叙事与“痕迹—本体—规则”

**原问题：** 消费者心里存的是概念关系、文字陈述，还是有先后顺序的经历？

“场景—品牌”“产品—品质稳定”等联想提供了关系视角；先好后差、先差后好又让事件顺序与解释叙事变得重要。我们选择暂时保留概括性状态和时间有序的事件记忆，不急于认定大脑的唯一存储格式。

人类和语言模型在输入、处理与输出上的相似性，为建模提供了参照；它本身不能证明两者具有相同的学习机制。

个人上下文系统的**痕迹—本体—规则**提供了工程参照：尽量保留可追溯记录，解释可以重构，旧结论可以被推翻。

**补充边界：** AI 能持久保存文字记录，不代表文字包含原始体验的全部信息，也不代表模拟中的消费者能无成本调用所有记录。外部档案、可提取记忆和思考预算，需要分开处理。

### 11. 从平均好感进入信念更新：品牌可能只是波动，也可能真的变了

**原问题：** 很多次好体验之后，一次坏体验应当造成多大改变？连续异常为什么又不同？

我们用两个竞争解释演示贝叶斯更新：品牌仍然稳定，或品质机制已经变差。合成设定下，连续三次坏体验可以显著提高“已经改变”的主观概率。这里的低先验、坏体验概率都是人为设定；不是把过去 99 次好体验直接代入就得到的估计。

不同人的行动门槛又造成反馈：谨慎者更早停止购买，宽容者继续试用；若品质恢复，后者有机会更新，前者可能长期保留旧判断。第三方信息能否促使回流，还取决于来源可信度及是否被接触。

**得到的认识：** 学习、行动和未来证据相互影响。固定双假设算例演示了这一点，但它还不是完整的在线变点检测模型。[信念更新与干预记录](../experiments/archive/05-experience-and-belief.md)

### 12. 重复与证据：熟悉、可信和想买不能合为一个量

我们讨论了信息反复出现后的熟悉感、提取便利和主观可信度，以及不同证据对品牌动机的影响。重复同一句话与提供来源不同的新证据，可能作用于不同过程。

**形成的约束：** 不能把同源转述机械地当作多份独立证据相乘；若要模拟人把重复误当证据，需要把它明确写成待检验的主观更新规则。被记住、认为可信、产生需求和发生购买，应分别观察。

### 13. 信息丰度：从“多少人知道”进入“谁知道、大家怎么看彼此”

行业经验把社会互动带入主线：多人看到信息后，可能更容易交谈，也可能认为品牌具有社会可见性。“信息丰度”保留为工作术语，其物理学类比用于启发命名，不能直接提供社会传播定律。

我们逐渐拆开三个方面：实际有多少人知道，知晓者分布在哪里，人们认为周围有多少人知道。共同可见性又会影响二阶判断，即“我认为别人知道什么”。

**修正了两种等同：** 媒介是公共形式，不保证产生充分共同知晓；信息形成热议，不保证品牌成为默认选择。高曝光也可能触发负面归因。聊天中个别商业品牌的争议和广告破圈故事，作为用户观察或线索保留，不写成已核实商业事实。[信息与协调记录](../experiments/archive/06-information-and-coordination.md)

### 14. 协调行动与第一个正式 ABM

**协调思想实验：** 在 SaaS 采购情景里，使用者、采购者和决策者的知晓与相互预期，会影响谁先提议、如何评估与何时批准。模型可以演示共同讨论怎样改变行动时机；它没有证明共同曝光足以完成采购，也不能把共同看见等同于严格的共同知识。

**正式计算：** ABM-001 将一个传播问题落实为十人环形网络、同步更新和门槛规则。同样六人初始知晓，门槛为 2 时，连续布点保持六人，穿插布点下一轮成为十人；门槛改为 1 时，两组最终都达到十人，但速度不同。

**资产状态：** 仓库已有引擎、自动测试、四份结果日志，以及覆盖全部 2,048 个初始状态与门槛组合的轨迹核验。复跑口径和本次检查结果以[实验记录](../experiments/abm-001-information-diffusion.md)及[核验说明](../models/verification-validation.md)为准。

**适用范围：** 这里模拟的是知晓传播，没有模拟信任、购买、收入或广告增量。寻找更复杂网络中多轮传播的 H02 仍保留在待办，当前不作为恢复研究的第一步。

### 15. 重新问消费者为何需要记住品牌：任务先于品牌清单

**原问题：** 消费者真的有必要把每个品牌都保存成一个认知状态吗？

用户提出以 Jobs to Be Done 理解消费者：生活里有待办任务，品牌承载解决方案的压缩信息。去屑、招待、送礼、身份表达等任务，可以调动不同的品牌联想和期待。

**研究推进：** 需要保存的状态，由任务和预测目标决定，不能预先规定所有消费者都需要同一组固定的三项或四项状态。“品牌Token化”在这里与降低判断成本相接，但品牌的功能、情感与社会意义仍然需要保留。

**已经完成的概率演示：** 保持某人对两个品牌的属性评价不变，只改变任务对两个属性的重视程度。在人为评分设定下，品牌 A 的选择概率可以从约 86% 变为约 14%。这一变化来自任务权重，无需先改变该人的品牌记忆。

**口径：** 演示假定已经决定购买、两个候选都可见且价格与可得性相同；概率分母是这两个候选之间的选择机会。它不是市场购买率，也没有包括不买或选择第三个品牌。[任务条件选择演示](../experiments/archive/07-tasks-and-brand-retrieval.md)

### 16. 思考预算、第一提及与开创品类

**原问题：** 一个消费者拥有很多知识，是否会在每次选择时全部调用？

系统一、系统二帮助我们讨论快速判断与费力比较；具体计算仍需要说明时间和精力怎样影响提取与选择。目前有两类候选机制：只来得及提取较少候选，或在候选不变时采用更简单的行动规则。两种机制尚未完成对照计算或真实检验。

TOM 被定义为给定提示下的第一品牌提及，不能直接当作稳定不变的品牌名次。提到“水”与描述具体任务，可能调动不同路径；想起品牌之后，还要受到评价、价格与渠道等条件影响。

“开创品类”也被拆成更可检查的问题：消费者是否接受新分类？任务能否自然唤起这个分类？分类又能否唤起品牌？品类标签让人想到某品牌，尚不能证明现实任务会自然走过同一条路径。

**提出但未执行：** 比较自然场景描述与加入品类标签后的无提示品牌提及。这样的实验首先测即时提示效果；长期学习、自然情境迁移和实际销售需要其他设计。[TOM 与品类提示记录](../experiments/archive/07-tasks-and-brand-retrieval.md)

### 17. 真人研究放在哪里，公开证据如何接入

用户提出可以承担简单问卷费用，也可能邀请高校传媒方向的学生协作。我们讨论了问卷口径、抽样、随机分组和样本量，但没有招募、发送问卷、支付费用或联系合作方。

**已有规划结果：** 二组比例比较的样本量可以先按假设效应估算。例如，在双侧 5% 显著性水平、80% 检验功效、两组人数相等的规划下，从 20% 提高到 40% 与从 20% 提高到 25%，所需人数相差很大。演示中的约 20–30 人只能帮助查措辞和流程，不能被说成普遍足够的正式样本。具体数值和假设见[真人研究记录](../experiments/archive/08-human-evidence-and-replication.md)。

**当前决策：** 不立即发问卷。先利用公开论文和公开数据。只有在关键机制分歧、必要参数或目标市场预测确实需要新数据时，再安排真人研究。

真人数据应明确用于提出机制、校准参数还是独立检验。用于调参的数据，不能又被当作未接触的验证集。便利样本的随机分组，也不会自动带来对全部消费者的代表性。

### 18. 暂停之前，已选定一个更小的下一步

最后一次收缩目标，选定 Lai 与 Gershman 2024 年关于奖励与策略压缩的研究作为候选起点：比较可用时间从 2 秒缩短到 1 秒时，参与者在惯常动作并非最优的条件下，选择惯常动作的比例怎样变化。

**已经完成：** 找到论文、公开代码与数据入口，确认它与“思考时间有限时如何选择”有关。

**尚未完成：** 下载和核查具体数据、复算这一对照、画出结果、检查能否与原文一致。没有在 Brandtopia 中拟合该模型，也没有据此得到消费者品牌选择结论。

用户随后提出暂停，先做本次完整回顾和仓库同步。这个复算任务保留为恢复入口，不在归档过程中继续执行。[暂停状态与下一步](current-state.md)

## 三、当前保留的统一结构

| 位置 | 目前的约定 | 尚未确定的部分 |
| --- | --- | --- |
| 顶层 | IPO：输入、内部处理、输出，行动反馈成为新输入 | 各场景采用什么最小状态和转移规则 |
| 输入 | 信息和事件保留来源、时间、对象与情境 | 不同模态、来源与注意力如何量化 |
| 内部处理 | 任务影响提取和比较；经历可能更新信念与联想 | 候选提取、资源限制、学习和遗忘怎样组合 |
| 记忆 | 概括性认知与可追溯事件并存；区分外部记录与当下可提取内容 | 何时检索具体事件，如何重新压缩 |
| 行动 | B=MAP 用于检查动机、能力和提示；具体概率需另行定义 | 哪种决策规则最适合当前任务 |
| 群体 | 个体状态、关系分布、互动和对他人知晓的判断可影响结果 | 什么社会机制在什么市场有增量解释力 |
| 工程 | 从明确的小规则开始，可用解析概率，不必每一步抽样或调用 LLM | 何时引入 LLM、更多状态或更大规模 |
| 证据 | 思想实验、计算核验、外部论文和本项目真实数据验证分别记录 | 本项目还没有完成现实消费者预测验证 |

B=MAP 的其他拼写在早期对话中属于转录错误。本项目没有另行采用一个名为 BDMIP 的框架。

## 四、必须一起保留的修正记录

研究积累也包括删去或收紧过的判断。各项来源、保留范围与修订原因另见[修正记录](../evidence/corrections.md)。

| 早期容易产生的理解 | 目前保留的判断 |
| --- | --- |
| 一次行为就能确定个人门槛 | 要考虑未控制的原因，并通过有区分力的条件与重复观测更新判断 |
| 人多了就能自动抵消不确定性 | 共同冲击、相关行为和模型错误仍会保留 |
| 拟合出一个恢复平台，就找到了真实机制 | 多种机制可产生相似历史走势，需要额外观察或干预 |
| 伦敦论文验证了我们画的客流恢复曲线 | 论文提供路线学习证据，合成恢复曲线保留为条件假设 |
| 广告带来的用户长期必然比促销用户留存好 | 早期结果受到不对称设定和状态口径影响，现实结论未成立 |
| 所有“保留”参数为零，就必然当期无人购买 | 还要检查初始状态、基础购买者、购买后刷新与更新时序 |
| 自然长出的 S 曲线证明了某个频次阈值 | 它只说明阶段规则能够生成该形状，规则和参数仍需检验 |
| 贝叶斯更新等于每次重复都增加独立证据 | 必须处理来源依赖；主观误判与规范推理分别建模 |
| 公共广告、共同知识、信任和购买可以串成必然链条 | 各环节需要各自的观测与比较，媒介形式不能代替机制 |
| 只要 Agent 足够多，便可以取代真实观测 | 模拟规模不能自动保证行为规则和输入的现实有效性 |
| AI 保存全部文本，就能模拟无遗忘的人类 | 存储、提取、注意力和行动时的资源限制需要分别处理 |
| TOM 就是最终选择概率 | TOM 依赖提示与人群，选择还需要通过其他行动条件 |
| 一小批问卷能同时解决机制、参数和预测验证 | 数据用途、样本精度与验证留出要分别规划 |

## 五、我们已经拿到的东西，以及仍没有拿到的东西

### 已经形成并能够接续

- **一条研究主线：** 规则与识别 → 学习与记忆 → 个体选择 → 社会互动 → 任务与思考成本。
- **一套共同语言：** IPO、B=MAP、痕迹—本体—规则、品牌Token化、信息丰度，以及分层证据口径。
- **一组思想与概率实验：** 用于暴露机制差异、检验设定的后果；完整参数是否保留由各实验记录说明。
- **正式 ABM 计算基线：** 信息扩散代码、黄金序列、自动测试与可复跑日志。
- **可接入的外部证据：** 强迫尝试、记忆提取、品类结构、品牌显著性和时间压力等研究；公开入口与可获取数据的程度分别登记。
- **协作载体：** GitHub 保存当前基线、实验来路、来源、修正和继续位置，使其他成员与 Agent 可以接续。

### 尚未完成

- 尚无经过本项目独立检验的真实消费者群体预测模型。
- 尚无能够估算真实广告增量、长期品牌回报或预算最优分配的参数体系。
- 尚未执行本阶段提出的真人问卷或正式合作研究。
- 尚未完成所选时间压力公开数据的单项复算。
- 尚未把所有讨论过的认知机制整合为一个经过核验与现实验证的 Agent 系统。
- 未保存的口头变体、部分旧版营销演示仍有来源缺口；没有把缺口包装成完整复现。

## 六、暂停与恢复安排

**现在：** 研究停在归档状态。没有问卷等待用户发送，没有合作方等待联系，也没有要求用户继续回答理论问题。

**恢复时的第一件事：** 复查一个已有公开实验的结果。用直白的问题表达就是：在已经学会怎么做的任务里，时间变紧后，人会不会更常使用惯常动作，即使那一刻另一个动作更好？

最小交付只需说明数据怎样对应两种时间条件、各是什么比例、结果是否与论文一致。再根据复算结果，决定是否值得给 Brandtopia 增加一个关于思考预算的机制。公开实验中的动作选择不会自动转换为品牌选择参数。

**后续候选，尚未排期：** 比较候选提取与简化决策两种机制；检查自然任务与品类标签的提示差异；修订广告与促销的共同状态模型；扩展 ABM-001 的多轮传播网络。它们保留为备选，不要求同时推进。

## 七、研究材料与协作方式的沿革

此前的广告归因与消费者认知研究，为本项目提供了 B=MAP、品牌Token化、信息分布和认知学习等来路。Brandtopia 保留独立的研究问题，不以证明某种媒介必然有效为目标。已有研究底稿的版本与授权边界见[来源登记](../evidence/source-register.md)；本次公开归档使用可共享摘要。

旧材料还包含 Brandtopia Town 的生活流、社交流和分层记忆原型，以及比较静态画像、个人经历与社会关系的方案。这条支线保留为设计来路；原型彩排、计划中的真人对照与本仓库已核验的 ABM-001，各有不同状态，不能合并为已经完成的现实验证。

协作方式也经过调整。用户希望继续在主对话中探索理论，由 Agent 承接具体计算与文档工作，避免自己在多个工作界面之间来回协调。GitHub 因而成为人和不同 Agent 共同读取的研究基线：先恢复当前问题与状态，再接续实验，把新证据、失败和修正写回同一仓库。

第一次建库主要记录了早期框架和信息扩散基线，后续认知、任务、TOM、思考成本与真人研究讨论没有及时同步。本次归档补齐这段差距，同时保留源码、计算记录和未完成标记。未来阶段性结束时，应同步更新研究状态、实验档案、来源与修正记录，再提交版本；不能仅靠另一段聊天摘要充当长期主本。
