# Brandtopia 的研究历程

## 从消费者的经历，走向群体行为的模拟

Brandtopia 的起点是《基地》中的心理史学：如果一个人的下一次行动难以预测，理解个体的行为机制，能否帮助我们预测一群人的变化？

我们把这个大问题落在消费者研究上。一个人怎样想起品牌、理解广告、改变判断、选择产品，又怎样影响身边的人？如果这些过程可以用少量可复用的规则描述，群体结果能否从中生成？

这份文档讲研究为什么一步步走到今天。具体实验、数值、修正和未完成事项见[完整阶段回顾](../research/2026-11-22-recap.md)与[实验档案](../experiments/index.md)。归档日期为 **2026-11-22**，不代表所有实验都在这一天发生。

## 1. 首先学会把一个问题说清楚

最早的参与和传播小实验，让我们看到：只有“每个人遵循什么规则”还不够。谁先参加、每个人看到的是哪一轮的状态、行动按什么顺序发生、观察到第几轮，都会影响结果。

接着遇到另一个问题：同一个结果，可能来自不同规则。某个人没有参加，既可能因为支持人数未达到门槛，也可能因为临时有事。只有设计能让不同解释产生不同预测的条件，才有机会区分它们。

这形成了第一个研究习惯：**每次都说清设定、比较对象、观察窗口，以及什么结果会让我们改变判断。**

## 2. 从“走势像什么”，转向“什么过程产生了走势”

通勤路线的讨论使这个问题具体起来。原路线停运，消费者被迫尝试其他方案；恢复通车后，有些人回来，有些人继续使用替代方案。

由此产生了几种需要区分的机制：人们是否发现了更好的路线？是否只是暂时没注意到已经恢复通车？停运时间是否影响替代方案的使用习惯？恢复速度与最终恢复水平是否由不同过程决定？

我们用合成曲线演示了这些可能性，也参照伦敦地铁罢工的公开研究。论文支持“被迫尝试可能带来学习”这一方向；它没有验证我们画出的那条客流恢复曲线。预测未来需要知道曲线背后的过程，单靠把历史走势拟合得更精细，无法完成这件事。[实验与来源](../experiments/archive/02-routes-and-path-dependence.md)

## 3. 相同的销量，可能藏着不同的消费者

价格实验把识别问题带回营销。优惠期间同样有四个人购买，取消优惠后可能产生不同结果，因为这些人接受原价的程度不同。

广告与促销的比较又往前推了一步：广告可能改变知晓和评价，补贴可能改变当次行动条件。两种投入即使产生相同的短期购买人数，也不意味着后续状态相同。

但我们也发现了模型里的偏向：如果预先让广告带来的消费者更接受原价，让促销消费者更依赖折扣，长远广告占优就会成为规则安排出来的结果。早期“广告长期留存更好”的表述因此不能当作现实结论。模型还暴露了零保留设置、购买后刷新和固定基础购买者之间的口径问题。

这段经历把研究标准提高了一步：**先检查结论是不是已经写在假设里，再判断模拟有没有提供新的理解。**

## 4. 广告进入一个已经存在的认知系统

消费者接触广告前，已经有记忆、联想、期待和使用经历。同一条信息，对陌生消费者可能是在建立新联系，对熟悉消费者可能只需唤起已有联系。

“怕上火”和王老吉的讨论，帮助我们把广告的作用从“看过几次”推进到“哪条联系被建立、强化或改变”。早期研究中的**激活、绑定、重塑**也在这里获得了位置。

我们尝试用分阶段学习解释不同形状的响应曲线，并讨论停投之后的衰减。曲线可以从明确规则中产生，但规则本身仍需证据检验；某次合成演示中的接触次数和半衰期，都不是行业通用参数。[学习与记忆实验](../experiments/archive/04-learning-and-memory.md)

## 5. 体验会改变判断，也会改变今后获得证据的机会

某餐饮品牌的去标识案例，将广告、首次尝试、多次使用、产品之间的差异、价格和共同决策放在了同一条旅程里。一次产品体验可以影响对该产品的评价，也可能影响对整个品牌的判断；同一家庭中的不同成员，还可能给出不同评价。

由此出现一个更重要的问题：一次坏体验意味着什么？经历许多次好体验的人，可能认为它是偶然波动；连续异常可能让他怀疑品质机制已经改变。

我们开始用贝叶斯信念更新做小型推演。消费者同时保留不同解释，新证据改变各解释的权重。随后又发现：停止购买的人无法继续获得亲身体验，继续购买的人则可能发现品质已经恢复。**行动会改变下一轮能够看到的证据。**

这些演示支持的是一种可计算的反馈机制。它们还没有证明真实消费者按某一组贝叶斯参数行动。[体验与信念实验](../experiments/archive/05-experience-and-belief.md)

## 6. 记住结论，也保留能够重新解释的经历

消费者往往直接调用“这个品牌靠谱”这样的概括判断，需要时才回想具体经历。这让我们的模型同时保留两类内容：概括性认知，以及带有时间、来源和情境的事件痕迹。

这里与个人上下文系统的**痕迹—本体—规则**相接：痕迹记录发生过什么，本体组织主体和关系，规则处理更新、检索与行动。新痕迹可以推翻旧解释；解释变化应当能追到依据。

不过，模拟人的 Agent 即使拥有完整外部档案，也不应自动拥有无限注意力和随时准确提取全部经历的能力。记录是否还在、当下能否想起、是否值得花时间检索，是不同问题。关系网络、叙事和事件顺序也可以并存，目前无需断言人脑只有一种存储格式。

## 7. 用 IPO 统一结构，用具体机制解释过程

研究逐步统一到 **IPO（Input—Process—Output）**：

| 层级 | 我们研究的内容 |
| --- | --- |
| Input | 广告、价格、使用体验、口碑、交流及环境变化 |
| Process | 提取已有认知，解释新信息，更新信念与行动预期 |
| Output | 购买、等待、放弃、搜索、讨论、推荐或协调行动 |

行为结果进入下一轮 Input，也会成为其他人的输入。**B=MAP（福格行为模型）** 帮助我们检查具体行动时的动机、能力和提示，但它没有直接给出经过校准的购买概率公式。

统一结构的价值，在于让不同输入能够作用于可复用的过程。我们并未确定一套适合所有消费情境的固定状态清单。需要保存什么状态，要由所研究的行为和能够获得的证据决定。

## 8. 群体里，不只有每个人各自知道什么

研究随后进入社会互动：“我知道这个品牌”“我认为同事知道”“大家知道彼此都知道”，可能支持不同的讨论和协调行动。

**信息丰度**由此成为工作概念。我们关心信息实际分布在谁那里、人们如何估计身边人的知晓，以及信息是否共同可见。To B 软件采购提供了直观例子：使用方、采购方和决策者之间的信息与预期，需要在行动中相互协调。

公共媒体和私人终端不能直接代替这些变量。电梯广告未必带来充分的共同知晓，数字媒体的公开讨论也可能形成很强的共同可见性。广告广为人知，还可能引发质疑。传播、信任、默认选择和购买，应当分别观察。

第一个正式 ABM 基线保存了这一方向中的一个小问题：在初始知晓比例相同时，仅改变知晓者在关系网络中的位置，传播结果就可能不同。它验证的是合成网络规则，尚未验证真实媒体的商业效果。[ABM-001](../experiments/abm-001-information-diffusion.md)

## 9. 消费者为什么需要品牌这种认知单位？

最近的讨论将研究进一步拉回消费者的生活任务。消费者需要解决去屑、送礼、招待、彰显身份等问题；品牌可以承载对解决方案的压缩认识，降低重新判断的成本。

这让**品牌Token化**的含义更清楚：品牌成为一个可提取、可承载多种期待的认知单位。它可以连接功能、情绪、社会评价和行动经验。这是一种建模视角，不是断言大脑使用语言模型的 tokenizer。

我们因此做了一个简单计算：保持同一个人对两个品牌的评价不变，只改变当次任务对两个属性的重视程度，选择概率便可能反转。这个演示让模型从“这个人总体喜欢哪个品牌”，推进到“这个人在当前任务下更可能选择哪个方案”。[任务与品牌提取实验](../experiments/archive/07-tasks-and-brand-retrieval.md)

## 10. 想到、比较与选择，需要时间和思考资源

熟悉品牌可能帮助消费者更快作出判断；进一步搜索和比较，则需要时间与精力。系统一、系统二提供了讨论这一差异的语言，但还需要将具体过程拆成可检查的规则。

目前保留着两种候选解释：时间紧张可能让人只提取少数候选，也可能让人面对相同候选时采取更简单的选择规则。我们还没有决定哪一种应进入 Brandtopia 的正式模型，更没有测定“几秒钟可以比较几个品牌”。

**品牌第一提及（TOM）**也被放回这个过程：它是在某个提示下首先想起的品牌，和最后选择存在距离。“开创品类”则可能改变任务、品类和品牌之间的提取路径；消费者是否自然采用这个分类，仍需观察。

## 11. 真实数据应该在什么时候进入？

我们已经讨论过小型真人研究的设计、样本量和用途，也具备寻找问卷与高校合作资源的可能。但当前没有启动问卷、招募或合作项目。

目前的顺序是：先利用已有论文和公开数据，找到与当前机制相关、能够复查的结果；等到关键模型分歧无法靠已有证据区分，或需要具体市场的参数时，再设计针对性的真人研究。

真人数据既可以帮助选择机制，也可以用来校准或检验模型。这几种用途要分开安排。Agent 生成的大量回答，不能自行充当真人验证样本。[真人证据与复算计划](../experiments/archive/08-human-evidence-and-replication.md)

## 12. 现在停在哪里，之后怎样继续？

我们已经有了研究主线、多个思想与概率实验、一个正式信息扩散 ABM，以及若干公开文献依据。**目前还没有完成对真实消费者群体行为的预测验证，也没有得到可直接用于品牌预算分配的模型。**

用户决定在这里暂停推进，先完整归档。恢复时，候选下一步只做一件事：用 Lai 与 Gershman 的公开研究数据，复查一个“可用时间减少时，惯常动作选择如何变化”的结果。资料入口已经找到，数据复算与结果图尚未完成。[暂停与恢复位置](../research/current-state.md)

贯穿这一路的检验标准仍然是：面对新的案例，已有机制能否复用？增加复杂性后，是否带来了更好的新情境预测？什么观察会让我们删去某个机制或改变研究方向？
