# Brandtopia 的研究历程

### 从心理史学的想象，到可以检验的微观生成机制

> 这份文档记录我们如何形成目前的研究问题。文中的机制是工作假设，合成实验与现实验证有严格区别。第一次接触项目的成员建议先读 [README](../../README.md)。

## 1. 一个问题：群体的未来能否计算？

阿西莫夫《基地》中的心理史学，从大量个体行为中寻找群体规律。Brandtopia 借用这个问题意识，但我们不预设已经能够预测文明未来。我们从消费者行为开始，因为品牌、价格、记忆、体验和社会互动，既有丰富的现实案例，也能逐步转化成可检验的计算实验。

市场研究能看到品牌认知、购买人数、销量或份额，却未必知道背后的微观机制。相同的销量增长可能来自促销、渠道改善或长期品牌偏好；它们可能在下一次环境变化后产生不同的结果。

**我们研究的核心，是从个体如何形成选择出发，理解群体结果如何产生，以及改变条件会怎样改变未来。**

## 2. 从宏观描述进入竞争性机制

研究初期，我们反复比较一个现象：两个市场目前表现相同，内部消费者却可能因为不同原因作出了相同选择。优惠取消或替代品出现后，市场可能分化。

由此，我们形成了一个方法约定：同时保留竞争性假设，寻找它们对未来不同的预测，并尽可能通过对照、干预和反事实思维加以区分。

历史曲线拟合得再漂亮，也不等于理解了背后的因果机制。我们更重视冻结规则之后，对新情境或新干预的样本外预测。

## 3. 从行为结果进入消费者内部世界模型

消费者看到广告时，已有自己的经验、品牌联想、价值判断和行动习惯。相同的信息对于陌生人和熟悉品牌的人，可能造成不同变化。

我们用“怕上火”和王老吉这样的场景联结来理解学习：信息可以建立新候选、强化已有联想，也可以改变人对某种解决方案的评价。广告、使用体验、社交评价都可能改变同一内部认知系统。

我们沿用了早期研究提出的三种操作语言：**激活、绑定、重塑**。它们表达信息进入已有认知后可能发生的不同作用，不是对媒介类型的机械划分。

我们也保留了“**品牌Token化**”的原始工作概念：品牌首先成为一个可识别、可检索、可继续承载意义的节点。它与大语言模型 tokenization 之间是功能类比，并非神经或机器学习机制上的同一。

## 4. 记忆、事件与贝叶斯更新

如果一个品牌过去许多次体验良好，最近一次体验不好，消费者可能将它看成偶然波动；连续异常则可能让他怀疑经营或产品质量机制已经发生改变。消费者更新的不仅是“喜欢多少”，还包括“原来的经验是否仍适用于未来”。

这使研究转向了**信念更新、预测误差和变点检测**。消费者可以同时保留多种解释，并根据广告、实际体验、其他人反馈等新证据调整其主观概率。

与此相连的还有记忆表示问题：概念之间存在联想，事件有发生顺序，叙事则可能保留对事件的解释。我们目前不主张人脑真实采用唯一的图谱或叙事存储格式；计算上暂时采用**概括性动态认知 + 时间有序事件痕迹**两层表示。

这里借鉴了“**痕迹—本体—规则**”的个人上下文架构。痕迹保留发生过什么、来源和时间；本体定义事物及关系；规则决定如何更新认知、检索历史和采取行动。旧结论可以被新证据推翻，原始痕迹则应该具备可追溯性。

## 5. 统一到 IPO，但保留学习机制的开放性

我们选择 **IPO（Input—Process—Output）** 作为统一架构：

| 层级 | 在消费者模型中意味着什么 |
| --- | --- |
| Input | 广告、价格、购买、使用、口碑、交流、环境变化等事件 |
| Process | 结合过去经历处理信息，更新信念、记忆、情境联结和行动预期 |
| Output | 搜索、购买、放弃、等待、分享、评价或协调行动 |

Output 会影响下一轮 Input，消费者的选择也会改变未来能够获得的信息。

**B=MAP（福格行为模型）** 用于理解具体行为时的动机、能力与提示；它本身并没有给出一个经过校准的购买概率公式。我们需要在 Process 中研究动态更新，在 Output 中比较各种具体行为生成规则。

## 6. 从个人学习进入社会认知与“信息丰度”

新的研究发现，仅仅“我知道一个品牌”还不够。消费者还可能关心：“别人知道吗？别人相信吗？别人是否知道我也知道？”这对于口碑、共同讨论以及 To B 多方协调都可能重要。

“**信息丰度**”是研究中保留的原始概念。它受物理学“丰度”及系统临界状态的启发，试图研究信息在一个人群内的实际分布、人们主观感知周围知晓的程度，以及共同可见性如何影响二次传播。

我们不预设公共广告天然更有信任感：公开讨论的数字媒体同样可以产生共同可见性；大量重复还可能引起对品牌的质疑。**信息广泛传播、品牌被记住、品牌获得信任、最终被选择，属于不同的结果。**

接下来要检验的是：在覆盖和内容相同的条件下，信息分布、人际关系、对他人知晓的判断，能否造成额外的行为差异。

## 7. 最难的理论命题：机制能否收敛？

现实生活里有无穷的具体因素：价格、情绪、需求、竞争、家庭讨论、广告信息、产品变化、社会事件等。逐个加入特例参数，模型可能无限膨胀。

Brandtopia 的核心假设因而进一步明确：**具体因素可能无法穷尽，但生成这些因素如何影响行为的底层机制，可能相对有限、可复用。**

这并不是已证明的“大一统理论”。我们必须让统一生成模型与更简单、适用范围明确的局部模型竞争；如果额外复杂性不能改善样本外预测和干预判断，应该减参、合并机制或承认适用边界。

## 8. 思想实验怎样进入可复现的计算世界？

我们先用简单的思想实验探索初始状态、时间顺序、干预、独立性、概率与人际连接，随后开始使用 **Agent-Based Modeling（ABM）**：每个虚拟个体拥有自己的状态与决策规则，行动改变环境及其他人的输入，群体结果由互动生成。

第一个工程基线研究合成社交网络中的信息传播，现已保存可运行代码、测试和结果日志。详见 [实验档案](../experiments/index.md)。这一结果验证的是程序能正确执行所设定的规则，不代表已经确认现实市场中的信息传播、信任或购买增量。

研究一直区分：**程序核验（Verification）**、**现实验证（Validation）**、**干预的因果识别**以及**样本外预测**。计算量增加不能自动修正错误的行为机制。

## 9. 未来怎样推进？

**理论线**继续探索学习与遗忘、贝叶斯信念、社会共识、信息丰度和最小生成机制。**计算线**将明确的规则落地为可复现的 Agent 系统。二者通过仓库共享研究基线，保留参数版本、原始证据、失败测试与修订理由。

现实数据通常稀缺、分散或不可授权获取。初期可使用公开文献、去标识的现实观察、合成模拟和可控小样本实验；条件成熟后，再用授权数据和真实干预对照校准。不能把思想实验或单个故事替代现实因果证据。

研究长期坚持一个判断标准：**面对新场景，能否复用更少的机制，产生更好的新结果预测，并清楚说明何时会失败。**
