# 假设与失败条件

下表用 H 编号追踪问题，用 C 编号追踪现有结论。试验前写明分析单位、比较基线、指标、窗口和有判断意义的最小差异。零结果应同时报告不确定性。

| ID | 可检验预测 | 比较或失败条件 | 当前证据 |
| --- | --- | --- | --- |
| H01 | 在 10 人环、两位不同邻居门槛下，同为六个种子，穿插组一轮多出四个知晓者，连续组没有新增 | 固定图与阈值，只改布点。黄金序列或独立规则推导不符就定位规格或实现 | 计算已核验，[C01](../evidence/claims-and-limitations.md#c01--布点改变合成环上的传播) |
| H02 | 在允许更大度数的网络里，固定两位不同邻居门槛可能产生两轮以上净新增 | 先找同为 10 节点、6 种子的最小反例图；以原环为对照。记录度数的变化，隔离同步／异步或人口变化 | 理论命题，待工程化 |
| H03 | 间隔接触和一致线索可改变学习曲线及停投后的留存 | 匹配接触量；分别测即时识别、无提示提取和停投留存。简单即时或恒定水平基线若在留出时间窗同样好，缩减机制 | 理论命题，S02 |
| H04 | 辨出同源转述后，其信念增量小于数量和可信度相匹配的独立证据 | 改变来源依赖或其可辨识性；记录前后置信度。如无可区分差异，检视来源识别与证据权重设定 | 理论命题 |
| H05 | 在覆盖、频次、内容和时点相当时，公共可见性先改变对同伴知晓的估计，在依赖协调的选择中可能产生额外效应 | 对照共见与各自私下收到的安排，测二阶信念和选择。若共见操纵成功且精度足以排除预设差异，缩小适用域 | 理论命题，S02、S07 |
| H06 | **品牌Token化**改善后续信息的正确归属和跨情境提取 | 控制品牌熟悉度和接触量；测归属准确率、混淆率与延迟提取，分别观察信任和选择。如果只提升熟悉度，收紧定义 | 理论命题，S02 |
| H07 | 显式区分认知、信任与行为条件，在新场景能更好预测选择或干预响应 | 对照简单曝光—选择模型，做时间或场景留出。预测无增益或无法识别各状态时，减参或合并状态 | 理论命题，S02、S03 |

**当前优先问题**：在保留阈值 2、同步更新和 6/10 起始覆盖的情况下，寻找产生多轮传播的最小图结构。随后再决定是否引入共见或信念强度；优先选可以直接对其测量和操纵的一项。
