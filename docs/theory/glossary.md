# 术语

| 术语 | 工作定义及最小观测 |
| --- | --- |
| 心理史学 | 群体层概率预测的研究隐喻。观测单位随问题确定，例如人群中知晓率随时间变化。 |
| IPO | 输入、处理、输出。建模时标出信息何时到达、状态何时更新、哪些输出可被下一轮读取。 |
| B=MAP | Motivation（动机）、Ability（能力或容易度）、Prompt（提示）在行动时刻会合。项目用它诊断行动条件，数值选择规则另行验证。 |
| 痕迹—本体—规则 | 痕迹记录发生了什么，本体规定对象与状态，规则决定在何种条件下如何变化。 |
| **信息丰度** | Brandtopia 原始工作概念。保留覆盖、分布、含义与相互可见等候选维度，可按研究任务选择测量。汇总权重和跨场景通用性待检验。 |
| **品牌Token化** | Joe 的原始工作概念。品牌名称、声音或图形等形成可识别、可区分、可检索、可挂载新意义的认知单位。与语言模型的文本切分是功能类比。原词亦写作「品牌 Token 化」。 |
| 知晓／品牌认知 | 知晓指知道某条信息或品牌存在。品牌认知还可包含归属、类别绑定、无提示提取和理解。每项测量应指明所覆盖的状态。 |
| 信念／品牌信任 | 信念是对某命题成立的判断。品牌信任可用对某品牌在某情境兑现某项承诺的置信或预期表示。 |
| 选择 | 在行动时刻，面对具体候选、成本和约束做出的决定，含不买或延后。 |
| 社会共识／共同知识 | 共识涉及理解的一致和相互可见。形式上的共同知识要求各成员都知道，且知道彼此知道的层级递归成立。 |
| 认知残留 | 触点消失后仍保留、且可在后续情境提取或改变选择的状态。可用延迟识别、无提示提取和后续行为分别测量。 |
| 收敛 | 固定规则下状态到达不动点，或随机模型在预先规定的统计精度下估计出稳定的结果分布。使用时注明具体含义。 |
| 因果增量 | 明确定义的干预和对照在目标单位、结果与观察窗口内产生的差异；网络传播时须说明干扰结构。 |

思想出处见[来源登记](../evidence/source-register.md)。改变项目原词的含义时，保留旧版本、提议的新定义和变更理由。
