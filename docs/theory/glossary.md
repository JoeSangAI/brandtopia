# 术语与口径

本表定义项目当前用语；科学来源、行业观察和项目假设的证据分开登记在[来源页](../evidence/source-register.md)。

| 术语 | 工作定义及口径 |
| --- | --- |
| 心理史学 | 来自《基地》的研究启发；在本项目中限定为对群体行为倾向的机制探索，不声称实现小说式历史预测。 |
| ABM | Agent-Based Modeling，多主体建模。明确个体状态、环境、更新规则和互动方式，再观察群体结果；不要求每个 Agent 使用 LLM。 |
| IPO | 输入、处理、输出。反馈使本轮结果进入下一轮或其他个体的输入。 |
| B=MAP | 动机 Motivation、能力或容易度 Ability、提示 Prompt 在行动时会合；不是三个概率相乘的购买公式。BDMIP 为早期转录错误。 |
| JTBD／待办任务 | 个体在特定情境下想完成的事情或取得的进展，可包含功能、情感和社会需求。 |
| 痕迹—本体—规则 | 痕迹保存事件及来源；本体与状态组织对象、关系和当前解释；规则决定何时提取、如何更新与行动。 |
| **品牌Token化** | 品牌符号成为可识别、可提取、可挂载经验和预期的认知单位。这是功能类比，没有确立人脑采用文本分词机制。 |
| **信息丰度** | 信息在特定人群中的实际覆盖、关系位置、感知覆盖、理解及相互可见等候选维度。没有已校准的通用单值尺度。 |
| 知晓 | 知道信息或品牌存在。ABM-001 只用二值知晓，没有直接实现信任或选择。 |
| 品牌预期／信念 | 对品牌在某任务或条件下兑现某种结果的判断；应带命题、情境与不确定性。 |
| 可提取性 | 在特定提示、时间和资源条件下，相关记忆能否被调用。不同于外部档案是否有记录。 |
| 考虑集合 | 此次决策实际纳入比较的方案；可以与消费者全部知道的品牌不同。 |
| TOM／第一提及 | 给定问题、线索和人群时第一个被提及的品牌。不能省略提示条件，也不能直接当作购买概率。 |
| 品类入口 | 需求、情境或其他线索使人想到品类及相关品牌的路径；不限定只有一个入口。 |
| 认知预算／思考成本 | 对搜索、提取、比较、判断所能投入的时间和资源的模型约束。尚无统一的“秒数→候选数”标定。 |
| 系统一、系统二 | 讨论快速直觉与较费力思考的加工特征；本项目不把它们当作两块独立脑区或现成的 Agent 方程。 |
| 共见 | 个体能观察到某次信息接触也对其他人可见；一种有限的设计或观测条件。 |
| 共同知识 | 群体知道某事，并知道彼此知道，且这种知道递归成立。共同接触、普遍熟悉和共识不自动满足该定义。 |
| 引爆 | 对快速传播的描述性用语。需另定义传播阈值、速度和范围；不等于品牌成为默认选择或产生销量增量。 |
| 选择概率 | 具体选择集、任务、约束下某行为的概率。需说明是否包含不买、等待或其他选项。 |
| 购买率 | 在明确的人群与时间窗内，符合购买定义的人数或机会数之比；人数与订单不能混用，TA 与触达人群不能互换。 |
| 贝叶斯更新 | 按先验和证据似然更新假设概率。固定两假设推演与随时间检测变化的模型应分别标注。 |
| 因果增量 | 某干预相对明确对照，在指定人群、指标和窗口内造成的差异；需要识别条件，不能仅由曲线拟合得到。 |
| 工程核验 | 检查实现是否遵守已写明规则，如边界、同步时序、概率守恒、日志回放。 |
| 现实验证 | 用适当的真实观察和设计检验预测或机制；用于调参的数据不能再次冒充独立留出验证。 |
| 收敛 | 至少区分三义：运行到固定点；重复模拟的估计趋稳；新案例增加时机制仍可复用、无需不断追加特例。前两者不能保证第三者。 |

修改项目原词时，保留旧含义、修改理由和所依据的证据，写入[决策记录](../governance/decision-log.md)。
