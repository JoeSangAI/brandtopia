# 研究框架：任务、认知、行动与反馈

本页描述正在形成的研究框架。[ABM-001](../experiments/abm-001-information-diffusion.md)目前只实现知晓传播；其余机制分别处于理论讨论、合成演示或待验证阶段，尚未接成一个完整消费者引擎。

## 1. 以消费者要完成的任务为起点

消费者可能要解决功能问题，也可能需要情感体验、社交表达或降低决策风险。品牌是可被调用的一种解决方案线索，承载过去的经验、信息和对未来结果的预期。消费者也可以选择其他品牌、其他品类、等待或不购买。

因此，状态怎样表示，应由问题决定。如果研究“今天想去屑，还是更看重香味”，就需要保留消费者对这两个结果的预期；如果研究采购协调，还需要知道谁参与决策、谁以为别人知道什么。早期讨论中的三类或四类状态都是局部简化，没有被确认为适用于所有消费行为的固定清单。[理论来路](../evidence/source-register.md)中的 JTBD、记忆检索与资源理性研究提供参考，具体结构仍须比较。

## 2. IPO 保留为顶层结构

| 环节 | 模型要交代什么 | 例子（含需间接测量的内部状态） |
| --- | --- | --- |
| Input：输入 | 接触的内容、来源、时点、顺序，以及实际可见范围 | 看见广告、收到评价、经历一次产品使用 |
| Process：处理 | 当下任务激活什么记忆；如何解释信息、更新信念；分配多少思考资源 | 想起某品牌、改变质量预期、把一次差体验解释为偶发波动 |
| Output：输出 | 面对候选、价格、渠道和提示，采取什么行动 | 购买、等待、放弃、讨论、推荐 |
| 反馈 | 哪些行动与结果进入下一轮或被他人观察 | 购买后的体验、家庭讨论、同事的采纳 |

“表征、学习、决策、互动”等分法，是对 IPO 内部过程及跨个体联系的进一步展开。采用它们时要说明对应接口，避免建立两套互相竞争的术语。

输入顺序可能影响处理过程，但是否产生顺序效应取决于具体更新规则。仅仅按时间存储事件，不保证模型已经实现叙事或变化点推断。

## 3. 痕迹、本体与规则各自保存什么

- **痕迹**：发生了什么、什么时候、来自哪里、谁能看见。外部档案保留原始材料与版本，不能用后来解释覆盖旧记录。
- **本体与状态**：当时采用哪些对象、关系、任务和信念概括经历。这些概括可随新证据修改或重建。
- **规则**：在什么情境调用哪些记忆，如何更新状态，何时作出行动并留下新痕迹。

需要区分外部记录和消费者可提取的记忆。档案可以保存得很完整，模拟中的消费者仍应受接触范围、遗忘、检索、时间和注意力约束。文本本身也只是对经历的记录，不能视作全部感官经历的无损副本。

关系网络、命题和事件叙事可以共存。我们尚未确立“所有脑内概念都用同一种格式保存”的神经科学结论。

## 4. 学习、提取与信念分别处理

一条广告可能同时增加熟悉度、强化任务关联、提供质量证据或成为当下提示。重复使用也可能提高信任、造成失望，或改变对稳定性的判断。模型应明确每条输入作用在哪个状态，避免将几个结果都归入一个“品牌好感”分数。

已讨论的候选机制包括：

| 问题 | 当前采用过的简化 | 仍待比较的解释 |
| --- | --- | --- |
| 低频广告效果弱、之后加速 | 两个学习阶段产生 S 形响应 | 连续学习、注意力变化、群体异质性也可能产生类似曲线 |
| 熟悉品牌容易被提醒 | 已有长期关联，加上短期可提取性 | 快慢成分如何测量、是否需要分开 |
| 停投后还会被选择 | 记忆、体验或自然接触维持部分状态 | 存储衰减、检索困难、购买刷新怎样区分 |
| 连续差体验引发质量怀疑 | 固定两个质量假设的贝叶斯更新 | 真正的“最近换厨师”需要动态变化点或其他时间机制 |
| 同一句话重复后更可信 | 熟悉感可能影响主观判断 | 同源重复与独立证据应如何加权 |

给定假设和证据，贝叶斯后验赔率可由先验赔率与似然比更新。多条证据只有满足相应的条件独立要求，才可以直接相乘各自的边际似然比。重复播放同一条广告不能自动得到多份独立证据。

具体公式和证据范围见[学习档案](../experiments/archive/04-learning-and-memory.md)、[体验与信念档案](../experiments/archive/05-experience-and-belief.md)及[纠偏记录](../evidence/corrections.md)。

## 5. 从认知到行动：B=MAP 与思考成本

B=MAP 用动机 M、能力或容易度 A、当下提示 P 理解具体行动条件。它帮助检查“有意愿、做得到、此时被触发”是否同时具备。它不直接规定购买概率，也不等同于将三个概率相乘。原始说明见[福格行为模型](https://behaviordesign.stanford.edu/resources/fogg-behavior-model)。

价格可以影响支付能力，也可以改变“值不值得”的判断；不能把所有价格作用都归为 A。广告既可能学习性地改变未来认知，也可能仅在当下发挥提示作用。

思考成本是另一条需要明确建模的约束：个体知道很多，并不意味着每次都会充分搜索和比较。后续须区分：

1. **检索受限**：某些方案当时没有被想起。
2. **选择简化**：方案已经被想起，但个体采用更省力的选择方式。

当前任务选择演示已把所有候选直接给出，只说明任务权重改变能改变条件选择概率；它没有测试候选如何进入脑海，也没有测试真实的时间压力。见[任务与品牌提取](../experiments/archive/07-tasks-and-brand-retrieval.md)。

## 6. 品牌Token化、TOM 与品类

**品牌Token化**是项目保留的工作概念：品牌名称、图形、声音等成为可识别、可检索，并承载任务关联和预期的认知单位。它是功能类比，不能据此推断人脑按语言模型的分词方式运作。

**TOM（第一提及）**是特定提示、问题和人群下的观察结果。品类提示和真实任务可能唤起不同品牌；首先被说出、进入候选、最终被选择分别需要记录。

“开创品类”提出一个研究方向：消费者会不会接受新的分类，并在以后需要时主动调用？新标签在问卷里立即改变答案，只能支持提示效应。要判断持久的分类学习，还要看离开标签后的提取与选择。

任务可以直接连接品牌，也可以经由品类再找到品牌；模型不预设所有选择都必须经过同一条路径。

## 7. 信息丰度与群体互动

**信息丰度**保留原始研究直觉，并拆成可区分的量：实际有多少人知道、信息分布在什么关系位置、个体以为多少同伴知道、彼此能否看见接触和回应。当前没有经过验证的单一汇总公式。

共同知识要求“大家知道，而且大家知道彼此知道”的递归层次；共同曝光只提供一种可能的条件。电梯或数字媒体的渠道名称，无法单独决定它是否产生共同知识。

传播、信任、协调和购买也须分别处理。同一个广泛投放，可以被解释为质量保证，也可能被解释为营销过度；同事都知道某 SaaS，有助于谈论和启动采购的假设，不等于软件适用性已经被证明。见[信息与协调档案](../experiments/archive/06-information-and-coordination.md)。

## 8. 怎样控制复杂度

先固定一个任务和一个可观察结果，再比较最简单的模型。只在旧模型无法解释一个有用的对照时，引入新的状态或机制，并记录代价、测量方式与能够推翻它的结果。

同一套规则可以容纳新的品牌、产品、任务和事件，不必每遇到一个案例都新增规则。是否收敛，最终要看新增案例下能否复用、参数能否识别、预测是否优于简单基线。无限算力不消除资料缺口，也不能保证模型本身正确。

目前可以使用确定性状态更新、概率分布或显式个体模拟；是否加入随机抽样、LLM 决策或大规模 Agent，由研究问题决定。当前没有把“大量 LLM 角色回答”视为消费者数据。
