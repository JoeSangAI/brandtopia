# 从个体更新到群体结果

## IPO、B=MAP 与痕迹—本体—规则

在一轮中，**Input** 是 Agent 可接收的线索或事件，**Process** 是依据当前状态处理线索和更新状态，**Output** 是新状态与可观测行为。输出形成时间有序的事件，并在满足可见性条件时成为别人的输入。v0.1 的输出只有新增知晓事件和累计状态。

B=MAP 用动机 M、能力或容易度 A、当下提示 P 理解具体行动。可先用于诊断提示是否发生、选择是否可行、动机是否够强。将它写成可预测行为的数值规则需要另行选型与校准。参见[福格行为模型](https://behaviordesign.stanford.edu/resources/fogg-behavior-model)。

「痕迹—本体—规则」在本仓库采用以下工作定义，供模型与日志对照：

- **痕迹**记录发生过的事件及其来源、时间和可见范围。
- **本体**定义参与者、信息、品牌、关系、情境，以及可变状态和取值。
- **规则**规定读哪些痕迹、如何更新状态、何时生成新痕迹。保留版本便于用同一输入比较规则。

## 从三人门槛到十人概率

三人情景便于分辨来源口径。以三人为例，可以让第三人在听到一位熟人后更新，也可以要求来自两位不同人，两条转述若同源则另计。此处只展示一种可检验的三人场景，早期原对话的具体角色和数值待回查（[S01](../evidence/source-register.md#s01--介绍心理史学)）。扩大到十人时，先标清「门槛」数的是局部来源、全体知晓者，还是感知到的同伴支持，再选择概率模型。

若两个独立邻居分别以概率 p 知晓，至少一位知晓的概率是 1−(1−p)²，两位均知晓是 p²。若十人环恰好均匀随机选六个知晓种子，并条件于焦点未被选中，其两位指定邻居均为种子的概率是 (6/9)×(5/8)=5/12。固定六人且已知位置时，直接逐人检查邻居即可。真实网络还可能有共享信源、群聚和选择性接触。见[实验 15](../experiments/abm-001-information-diffusion.md)与[复杂传播参考](https://www.journals.uchicago.edu/doi/full/10.1086/521848)。

## 学习、停投与贝叶斯信念更新

品牌学习可从接触写入、重复巩固、情境提取和经验回写拆开。比较投放期间的学习曲线，以及停投后在相同测试时点和提取线索下的变化；记录停投窗口内的口碑、使用、竞争接触和自然刷新。辅助识别保留而无提示提取下降，支持进一步比较提取失败和存储衰减。快慢成分、边际递减、饱和和衰减曲线均属待比较假设。见 [S02 §7、§10、§13](../evidence/source-register.md#s02--生成模型视角下的营销科学)。

给定声明 H 和证据 e，后验赔率等于先验赔率乘以似然比 `P(e|H)/P(e|¬H)`。多条证据只有在给定 H 及 ¬H 时可视为条件独立，才能直接相乘各自的边际似然比；一般应使用条件似然或联合似然。把可信首发、同源转述和独立体验分开建模。这里的 H 可指一项产品承诺；知晓 H、相信 H、认出是哪个品牌、随后选择该品牌各有单独的观测。

## 信息丰度、共见与共同知识

「信息丰度」保留从信息分布、公共知晓到社会共识的研究直觉。候选维度是触达及空间或网络位置、理解一致性、来源独立性、在决策时的人际可见性。可另外测量「我估计多少同伴知道」及「我是否知道同伴也能看到这次接触」。这些是低阶代理。共同知识要求群体知道某事、知道彼此知道，且这种层级继续递归。

同一信息可被许多人私下看到，或在彼此可见的公共场合被看到。可以固定覆盖、频次、内容、来源与时间，再操纵共见线索，比较对他人知晓的估计、转述、信任和选择。公共与私域是渠道描述，实际共同可见性需要单独操纵或测量。见 [S02 §18](../evidence/source-register.md#s02--生成模型视角下的营销科学)与 [Chwe，Rational Ritual](https://press.princeton.edu/books/ebook/9781400846436/rational-ritual-0)。

## 从品牌认知到选择

「品牌Token化」先让消费者能把新信息挂到一个可识别、可再次提取的品牌上。核心绑定和场景泛化让品牌在需求出现时进入候选集。信任、价格、可得性、风险及其他解法共同影响现场选择，购买体验又回写认知与信任。可在同一个实验分别记录识别、无提示提取、对具体承诺的信任、候选及最终行为。若要把这些变化归于外部投放，要先明确干预、时间窗、可比对照和网络溢出。
