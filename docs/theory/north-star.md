# 研究北极星

**少数可复用的个体机制，能在什么条件下生成可观察、可预测、可被推翻的群体行为？**

「心理史学」借用《基地》里的设想，提出群体规律的研究目标。Brandtopia 从小型社会开始，先验证一个局部规则如何产生整体分布和时间轨迹，再用独立观测检验适用范围。这个研究动机在 2026 年 7 月底稿附录 A8 已有记录（[S02](../evidence/source-register.md#s02--生成模型视角下的营销科学)）。

| 研究对象 | 要回答的问题 | 可区分的观测 |
| --- | --- | --- |
| 信息传播 | 谁在什么时候知道了什么，通过谁或哪个渠道？ | 到达率、传播时点、来源路径、内容保真度 |
| 品牌信任 | 在明确情境和产品承诺下，对结果有多大把握？ | 预期评分、置信度、收到新证据后的变化 |
| 品牌选择 | 在需求、价格、可得性和多个选项约束下，最后做了什么？ | 候选集、搜索、选择、放弃或延后 |
| 外部干预的因果效应 | 若在相同目标人群和时间窗改变投放或共见条件，结果会差多少？ | 有可比对照的状态或行为差值，标明网络溢出与不确定性 |

现阶段以知晓传播为起点。首个工程基线只开放初始位置和局部知晓阈值；先用它回答规则问题，再逐项加入关系网络、共见、记忆或信任机制。[实验履历](../experiments/index.md)记录已有探索，[假设清单](hypotheses.md)保留下一步明确可检验的问题。
