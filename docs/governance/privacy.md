# 公开仓库与资料边界

截至 2026-11-22，本仓库为 **Public**。项目所有者决定暂时保持公开，未来可在账号验证或团队协作需要明确后调整可见性。本文件描述当前实际状态；仓库公开意味着任何人都可能读取或复制已提交内容，之后改为私有也无法保证已公开副本被收回。

| 材料 | 处理方式 |
| --- | --- |
| 家庭成员及其他个人信息、个人 Agent 痕迹和私聊 | 原件、可识别细节、截图及敏感元数据保留在授权的私有位置；公开材料使用去标识摘要或合成示例。 |
| 未获许可的公司内部文件、客户数据、投放及经营复盘 | 不上传原件；只有确认可以对外共享的方法及足够抽象的研究内容才能纳入。 |
| 公开品牌案例 | 标注出处与时间，区分已证实事实、争议报道和个人观察；避免将未经核查的商业主张表述为已证实结论。 |
| 合成数据、实验参数与日志 | 显示“合成”标记，记录复现路径，同时核查元数据、日志及 Git 提交中的潜在敏感信息。 |

新增成员、外部集成或扩大数据分享范围，仍需遵守资料权属与项目授权。拥有仓库读取权限并不代表有权使用其背后未公开的研究原始材料。

若发现敏感资料误入公开仓库，应立即暂停扩散并按相应平台流程处理历史版本与已有公开副本；单纯删除当前文件不等于撤回历史数据。
