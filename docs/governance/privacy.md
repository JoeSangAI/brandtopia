# 私密仓库与资料边界

仓库初始设为 Private。新增成员、外部集成、公开可见性或对外分发，须取得项目所有者明确授权。能访问仓库不代表能访问原始来源。

| 材料 | 处理方式 |
| --- | --- |
| 家庭成员及其他个人信息、个人 Agent 痕迹和私聊 | 原件、可识别细节、截图及元数据留在原授权位置。用研究主题或合成事件表达机制。 |
| 未获许可的公司内部文件、客户数据、投放及经营复盘 | 仓库只采用可共享的通用方法或无可重识别细节的摘要。需要原始数据时按项目授权处理。 |
| 公开品牌案例 | 标明出处、日期及是可查事实、未核实报道还是用户叙述。无法安全共享时，用匿名设计讨论变量。 |
| 合成数据与实验日志 | 在实验页显式标记合成。复核路径、日志字段、代码注释及提交元数据里的可识别信息。 |

若需从旧资料转录，优先用来源编号、原稿版本、章节和去标识摘要。发现误纳材料时先限制访问并通知项目所有者，再按授权处理版本历史和任何外部副本。
