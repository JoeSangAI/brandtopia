# 参数与口径登记

下表把“已经实现”“为演示设定”“还不知道”分开。这里没有经真实消费者数据校准的通用广告、品牌或记忆参数。

## ABM-001 v0.1：已实现

| 参数或结构 | 当前值 | 依据与含义 |
| --- | --- | --- |
| 人口与拓扑 | 十个 Agent，无向环，每人两个不同邻居 | 固定邻居数下比较种子位置 |
| 初始知晓 | 连续组 0、1、2、3、4、5；穿插组 0、1、3、5、7、9 | 两组均为 6/10；库函数支持其他合法初始集合 |
| 门槛 k | 默认 2；对照 1 | 上一轮知晓的不同邻居人数 |
| 更新时序 | 同步离散轮次 | 轮次没有现实时间单位 |
| 持续性 | 知晓永久保持 | 不含遗忘、退出、信任、购买 |
| 停止 | 首个无新增轮，空轮入日志 | 达到此固定模型的不动点 |
| 随机性 | 无 | 同一输入产生相同结果 |

## 下一轮仍待识别的参数

| 候选 | 可以怎样观察 | 目前不知道什么 |

| 任务与品牌预期 | 相同消费者面对不同任务的提取、评价与选择 | 如何从数据分离任务权重与品牌预期 |

| 行动与体验反馈 | 候选、价格、渠道、提示、实际体验 | 如何连接认知指标、购买与利润，避免把相关当增量 |

## 指标分母先于计算

“购买率”至少要交代哪些人有资格进入分母、何时出现购买机会、以人还是订单计数、观察多长时间。某次二选一中 A 的选择概率，不能直接当作目标市场的购买率。

同样，TOM 必须注明提示与被访人群；曝光后的转化须定义曝光与转化窗口；延长窗口可能纳入更多事件，却不会自动证明更多事件由广告造成。实际效果比较还要记录预算是否真的等额、优惠由多少订单承担、是否蚕食原有购买以及所用收益口径。
