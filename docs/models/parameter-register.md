# 参数登记

## ABM v0.1

| 参数或结构 | 当前值 | 依据与含义 |
| --- | --- | --- |
| 人口与拓扑 | 10 个 Agent，环，无向，每人两个不同邻居 | 合成对照规格。固定邻居数下改变种子布局。 |
| 初始知晓 | 每个内置情景 6/10。连续组 0、1、2、3、4、5。穿插组 0、1、3、5、7、9 | 合成输入。库函数支持任意合法初始集合。 |
| 知晓门槛 k | 2 为默认及黄金测试，1 为规则对照 | 单位是上一轮已知晓的不同邻居人数。 |
| 更新时序 | 同步离散轮次 | 轮无现实时间单位，从第 0 轮起记录。 |
| 持续性 | 已知晓状态永久保持 | v0.1 结构假设。未配置遗忘或停投衰减。 |
| 停止 | 第一个无新增的轮次 | 空轮入日志，标示到达固定点。 |
| 随机性 | 确定性 | 无抽样种子。同一输入生成同一日志。 |

## 候选参数与校准口径

| 候选 | 单位或可操作设计 | 状态 |
| --- | --- | --- |
| 曝光强度、间隔与观察窗 | 次数、接触间隔、停投后实际时间。单独记录自然接触 | 记录方式待实验，跨品类频次阈值待证据 |
| 记忆保留与衰减 | 比较恒定、单速率和快慢成分，使用有无提取线索的延迟测量 | 曲线与半衰期待识别 |
| 来源权重与依赖 | 同源／独立来源、可信度操纵、置信度前后变化 | v0.1 无此参数 |
| 共见与感知同伴知晓 | 共见组分配，感知知晓比例与来源线索 | 可先作为不同变量；信息丰度的汇总权重待研究 |
| 行动条件与反馈 | 候选、行动成本、提示时点、结果或体验 | v0.1 无此参数 |

Town 草案中的记忆和多次运行设定属于其原型配置提议（[S05](../evidence/source-register.md#s05--brandtopia-town)）。候选进入可运行版本时，在本页补充合法范围、缺省值、选择依据、敏感性检验和对应实验。
