# 模型架构

本页分别列出正式引擎、独立的历史演示和未来接口。IPO 是共同的研究语言，当前还没有把所有机制接入一个消费者模拟器。

## v0.1 已实现

[入口 `brandtopia.py`](../../brandtopia.py)接收初始知晓集合和阈值，从第 0 轮推进合成十人环。对 Agent i，邻居是 (i−1) mod 10 和 (i+1) mod 10。每轮先读上一轮快照，计算新增知晓者和各自来源，再统一更新。本轮新增知晓从下一轮起可被邻居计入。出现首个无新增轮时记录并结束。

```text
D[t] = {i ∉ A[t−1] | |neighbors(i) ∩ A[t−1]| ≥ k}
A[t] = A[t−1] ∪ D[t]
```

| 组成 | 当前表示 |
| --- | --- |
| 本体 | Agent 0–9、固定邻接、单条信息、二值知晓状态 |
| 痕迹 | 第 0 轮初始集合，之后记录每轮新增 Agent 与其上一轮已知晓的全部邻居 |
| 规则 | 同步更新、门槛计数、知晓持续、首个空轮停止 |

日志结构为 `schema`、`threshold`、`initial`、`rounds`。版本是 `brandtopia.awareness.v0.1`。初始 ID 为升序去重列表。每个轮次有 `round` 与 `events`，事件有 `agent` 与升序 `sources`。事件按 Agent ID 顺序记录。回放校验每轮事件和来源，识别提前结束及多余轮次。

## 已保存、尚未接入引擎的独立演示

[7 份交互演示](../../artifacts/chat-demos/README.md)保留各自的规则：允许退出的三人系统、随机邀约、共同冲击、经历改变门槛、合成路线恢复、任务条件选择。它们不共享同一个状态协议，也不代表 ABM-001 已支持这些能力。

[归档计算脚本](../../scripts/verify_archived_calculations.py)复核旧公式，输出 [archive-calculations.json](../../results/archive-calculations.json)。脚本使用确定性计算和精确概率，不重新抽样过去的随机历史；也没有重新实现旧广告促销界面。

## 待建模的扩展

| 组件 | 最小接口与预期诊断 |
| --- | --- |
| 网络和可见范围 | 显式关系图。对每条线索区分接触对象和共见对象，先区分布点与传播规则。 |
| 任务与候选 | 明确正在完成什么任务、哪些方案进入考虑集合、是否允许等待或不购买。避免把所有已知品牌都默认当成已考虑。 |
| 信念与记忆 | 按任务决定是否需要命题、时间、强度、来源依赖与事件记录。引入新状态前给出一个能区分它的观测。 |
| 认知预算 | 区分真实接触、可提取记忆与当次决策资源；无限模拟算力不意味着 Agent 无限知情。预算影响提取还是选择策略仍待比较。 |
| 行为与反馈 | 选择发生在情境中，输入候选、约束与信任，输出可观察动作及可追溯的体验反馈。 |
| 外部干预 | 和内生传播分开记录注入事件及分配规则，保存对照条件与溢出边界。 |

v0.1 的邻居知晓状态由引擎直接读取。显式转述、信任、遗忘、共见、选择和 LLM 角色决策属于扩展议题。每次优先加入一条可独立检验的机制，详见[假设](../theory/hypotheses.md)。是否使用 LLM 决策和个体随机抽样由研究问题决定，不作为“进入 ABM 阶段”的前置条件。

当前研究暂停。候选恢复任务是公开数据的一个时间压力对照，并不要求先扩写引擎，见[当前状态](../research/current-state.md)。
