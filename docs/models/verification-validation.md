# 工程核验与现实验证

## 工程核验

Python 3.10 及以上，仅使用标准库。从仓库根目录运行：

```sh
python3 -m unittest discover -s tests -v
python3 brandtopia.py run interleaved --threshold 2
python3 brandtopia.py replay results/interleaved-t2.json
```

基线曾在 Python 3.12.5 下核验；2026-11-22 本次完整归档又用 Python 3.12.14 重跑，[9 项测试](../../tests/test_brandtopia.py)全部通过。测试用独立的最短路径与孤立缺口性质，对所有 1,024 个初始子集和两个阈值共 2,048 个配置检查逐轮轨迹。边界测试涵盖空集、全知晓、单点、环首尾关系、错误输入、回放与日志篡改。四份 JSON 经命令行逐字节复跑并通过回放。本次未修改 ABM 算法或旧日志。

## 历史示例的归档核验

```sh
python3 scripts/verify_archived_calculations.py --check
```

该脚本用标准库重新计算已讨论的合成例子，与[归档 JSON](../../results/archive-calculations.json)比较，并检查若干精确结果、概率范围、总概率及轨迹。三人时序、共同冲击、路线恢复、价格对照、贡献金额、旧残留公式、学习曲线、贝叶斯、任务选择及样本规划均已核对。

这里的结果是本次复算，不是假装找回的历史随机日志。它不修复尚未恢复完整源码的旧广告补贴模型，也不执行 Lai 与 Gershman 公开数据研究。

[七份演示原稿](../../artifacts/chat-demos/README.md)已按 SHA-256 保存；导出文件经原稿嵌入完整性和脚本语法检查。此轮没有做全部导出页面的浏览器交互、多尺寸视觉复审。计算核对、代码语法检查和用户界面验证分别记录，不相互替代。

## 判断收敛

v0.1 在有限人口上单调增加知晓者并抵达不动点。换成随机实现时，每个条件要报告配置、独立随机种子、跨轮轨迹、重复间变异、效应区间和停止准则。比较同一批种子下的干预与对照，并用独立种子确认可重现性。若出现分叉，先定位最早不同的事件，区分路径依赖、未建模条件与实现漂移。运行稳定性、跨场景可迁移性各有独立判断。

## 现实验证

1. 冻结机制、预测、比较基线和主要结果。将用于调整模型的样本与用于验证的时间窗、群体或场景分开。
2. 按目标采集知晓、信息归属、信任或选择。检验简单模型是否已达到同样预测表现。报告误差、区间与失败样本。
3. 估计因果效应时，明确干预分配、对照、时点及网络干扰。可考虑以群组为单位分配，或定义处理及邻居暴露以分别估计直接效应和溢出。
4. 若不同参数能产生相同群体轨迹，先增加能区分机制的独立观测，或简化模型。对超出已测人群、条件和时段的推广保留单独验证任务。

本基线的已完成记录见[实验 15](../experiments/abm-001-information-diffusion.md)。真实数据验证状态见[主张与局限](../evidence/claims-and-limitations.md)。

## 当前现实证据的使用顺序

先复用已有论文和公开数据，为竞争性机制提供约束；仍存在决定模型方向的缺口时，再投入真人调研。小样本试问卷主要检查流程，大样本效果估计应由具体效应、精度和分析设计决定。规划数值见[CHAT-20](../experiments/archive/08-human-evidence-and-replication.md)。

本项目尚未完成自己的真实消费者验证。下一候选公开复算也尚未执行；研究在[当前状态](../research/current-state.md)所列位置暂停。
