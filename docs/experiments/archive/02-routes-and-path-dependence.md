## CHAT-04 · 停运之后，为什么有人不再回来？

**状态：完成案例讨论、合成曲线推演与交互演示；查阅了外部论文。合成曲线没有用伦敦客流数据校准。**

### 问题怎样形成

消费者曾经选中的方案，可能只是当时已知条件下的好方案。之后世界改变了，如果没有事件让他重新比较，他可能继续沿用旧选择。停运提供了一次强制重新寻找路线的机会。

这一机制要求替代方案能完成原来的任务，例如相同两点之间的移动。需要比较的是时间、价格、便利性等结果；“出现了一个新选项”本身不保证人会切换。

对话提出的条件假设是：短期总通勤需求相对稳定；停运使部分原用户尝试替代方案；复通后有人回流，也有人留在替代方案；同期新增流入先作为较小变动处理。在这些条件下，原路线客流可以逐渐回升，并停在原水平以下。

### 已经画过的曲线

恢复的[演示源码](../../../artifacts/chat-demos/fragments/commute-recovery-curves.html)使用以下合成设定：

| 参数 | 设定 | 含义 |
| --- | --- | --- |
| 原用户数 $N$ | 1,000 | 示例规模 |
| 停运天数 $D$ | 可调 1—7 | 延长尝试替代方案的时间 |
| 每天留在替代方案的比例 $q$ | 10% | 从尚未留下的人中转出；人为指定 |
| 每天回流比例 $r$ | 可调 10%—90% | 从仍可能回流且尚未返回的人中返回 |

最终可能返回的人数为 $L=N(1-q)^D$；复通后经过 $t$ 天，预计返回人数为：

$$A_t=L\left[1-(1-r)^t\right].$$

演示把 $t=0$ 定义为回流过程开始的零点，设 $A_0=0$。这属于画图用的初始条件，不是对真实复通首日客流的断言。

例如停运 2 天、每天剩余可回流者的 50% 返回：

| 复通后的天数 | 预计返回人数 |
| --- | --- |
| 1 | 405 |
| 2 | 607.5 |
| 3 | 708.75 |
| 7 | 803.671875 |
| 14 | 809.950562 |
| 长期极限 | 810 |

这些是期望值，所以可以出现小数。停运天数通过 $L$ 改变长期水平；回流比例 $r$ 改变接近长期水平的速度。随着停运时间延长，绝对回流量和斜率也会变化；归一化后的恢复速度由 $r$ 控制。

**得到的计算结果：** 这套规则能生成“先快后慢、趋于较低水平”的回流曲线。曲线向上增长但斜率递减，数学上是向下凹；对话中曾使用“凸”的日常说法，归档统一上述口径。[归档复算](../../../scripts/verify_archived_calculations.py)

### 论文支持到哪里

Larcom、Rauch 与 Willems 的伦敦地铁罢工研究发现，外部中断促使一些通勤者尝试不同路线，并在正常运行恢复后继续改变通勤选择。研究支持“原有信息不充分，强制尝试可以改变后续选择”这一机制方向。[论文原文](https://ora.ox.ac.uk/objects/uuid%3A271f6f8e-2915-445f-8ebd-5a2900970af1/files/m8cbcb25268f8ae9d9fd6c1951fa05958)

它没有为上述指数曲线提供参数，也没有证明某站客流一定永久低于原值。其正常恢复后的观察窗口较短，个体路线改变也不能直接换算成整个地铁系统客流流失。对话中“停运越久越习惯新路线”的说法因此保留为待检验假设；信息发现、习惯变化和其他环境变化可能同时起作用。

## CHAT-05 · 看起来趋近 900，就能断言最终是 900 吗？

**状态：完成方法讨论；原口头数列的完整数值与竞争曲线未全部恢复。**

如果一个数列明确由已知公式生成，求极限是数学问题。如果只观察到一小段现实恢复曲线，“以后停在较低水平”和“还有一批人更慢地回来”等机制，可能都能解释眼前的数据。

对话中的“900”用于触发这个区别，不能把它写成伦敦客流的实测终值。继续增加同一条曲线上的点，有时只会使拟合更精细；补充另一类信息可能更有帮助，例如哪些人开始使用替代路线、原来的任务是否变化、替代方案是否实际更好。

**保留下来的研究方法：** 先列出不同机制各自预测什么，再寻找能区分它们的观察或干预。历史拟合程度、未来预测能力、因果识别是三个不同检验。
