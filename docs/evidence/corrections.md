# 判断修正记录

**归档日期：2026-11-22。** 本页保留我们发现的问题以及目前采用的表述。修正旧判断也是研究结果的一部分；这里记录的反例、限制和缺口不会被后来的整洁叙事覆盖。

## 1. “更多人／更多次模拟”能解决什么

早期讨论由个体偶然性走向群体稳定性。现在明确区分三件事：独立抽样产生的波动、共同事件造成的相关性、模型本身的偏差。

增加独立样本可以让样本均值更稳定，但下一次抽样没有补偿上一次结果的义务。同一公司的临时活动、同一家庭的共同决定等会使个体行为相关；即使人数很多，也不能直接按独立个体平均掉。扩大 Agent 数量不能修复错误规则、漏掉的共同冲击或缺失信息。

**当前状态：** 独立与共同冲击的合成例子可核查；真实消费者的相关结构尚未估计。参见[实验档案](../experiments/index.md)。

## 2. 门槛识别和价格识别都带条件

让一个参与者退出，可以使门槛 1 和门槛 2 产生不同预测；临时缺席也可能产生相同观察。因此一次没有参与，不能给出“100% 是门槛 2”的判断。

同样，观察到某人没有按 100 元购买，不能立即推出他最多只愿付 80 元。他可能没有需求、没有接触到商品、选择了替代品或没有购买机会。支付意愿区间只有在这些条件按设定固定时才能由价格实验识别。

**当前状态：** 识别问题已经明确；没有把合成条件当作真实消费者的不变属性。

## 3. 伦敦罢工论文与我们的恢复曲线分开

用户提出的曲线假设是：恢复运营后客流逐步回升，速度越来越慢，最终仍有一部分乘客留在替代方案。在需求短期稳定、回流不足以抵消流出等条件下，这是一种合理的待检验机制。

伦敦论文报告的是部分乘客在强制尝试后改变路线。它没有确认我们的站点总客流曲线，也没有证明差额永远保留，或两天停运已形成新习惯。[S08](source-register.md#s08--伦敦地铁强制尝试与路线调整)

此外，若曲线向上增长、斜率逐渐减小，数学上属于**凹曲线／向下弯曲**；对话早期用“凸”形容其外观不够准确。长期水平与回流速度也是两个不同参数，不应混为同一种效应。

**当前状态：** 合成曲线有明确公式与参数；尚未用地铁数据拟合或验证。

## 4. 广告比促销留存更好：撤回普遍判断

旧演示让广告新增消费者和促销新增消费者拥有不同的原价接受率及状态路径，还保留固定的基础购买者。长期曲线的差异包含这些人为设定，无法直接归因为广告本身。

“保留率归零后仍有人购买”的追查进一步发现：某些衰减只作用于未购买者；购买可能刷新记忆；零体验强化不等于清空已有偏好；固定基线也会继续贡献购买。另有接受率作用于显示输出，却没有完整进入下一轮状态流的缺陷记录。

**当前结论：** 需要让两种干预使用同一套状态转移和成本口径，再检验不同输入带来什么结果。此前的 3.4、2.98 等数值只解释特定旧设定；完整旧实现未恢复，不能声称已经修复并重新证明长期优劣。

## 5. 剂量与学习曲线不能由一句“边际递减”替代

单阶段更新可以产生从一开始就递减的增益；需要先认识、再绑定的分阶段机制可以产生先慢、后快、再放缓的曲线。这两种形状都来自相应规则。

因此，S 形曲线不是脱离假设“自然证明”出来的现实规律。原有熟悉度、间隔、注意、信息来源和反向解读都可能改变效果。频次正相关也应作为特定范围内的假设检验，不能先认定无限增加必然提高购买率。[S01](source-register.md#s01--介绍心理史学)、[S09](source-register.md#s09--重复与虚幻真实效应)

**当前状态：** 分阶段学习与停投衰减是候选机制；9–16 次的具体经验区间和演示半衰期尚未成为本项目实测参数。

## 6. 贝叶斯更新提供了抓手，仍缺完整的时间机制

“稳定品质”与“品质已变差”的两假设例子，说明相同坏体验怎样在不同先验下改变判断。示例中的 1% 是设定先验，不能说它由 99 次好体验直接计算得到。

固定两假设、观测条件独立的简单模型对同一批好坏体验的排列顺序不敏感。用户提出的“最近换了厨师／经营方式，所以旧经验需要重新解释”，还需要表示**变化何时发生**。这部分在线变化点机制尚未实现。

重复同一条广告也不能无条件当作独立证据连续相乘。主观熟悉感可以改变判断，但其更新过程需要另行说明；“重复得多”与“证据来源更多”不能共用未经检验的似然比。

**当前状态：** 合成后验及决策例子可复算；没有宣称人类按此公式精确更新，也没有完成变化点模型。

## 7. 经验、记忆与认知压缩的类比有适用范围

关系网络、概括性信念、具体事件和叙事都可以成为模型表示。我们没有证明大脑只用某一种格式储存概念，也没有证明人的学习等同于语言模型的 next-token prediction。

“痕迹—本体—规则”提供了有用的实现组织：保留来源，允许解释重建，为下次调用服务。人的记忆会遗忘或重构；数字档案可以保存更多内容，但文本记录仍会遗漏经历，存得下也不意味着一次调用时全能读到。

讨论中“所有 LLM Agent 只有文本输入”的表述也已修正：图像等多模态输入存在。[S19](source-register.md#s19--ai-输入能力的事实修正)

**当前状态：** 外部档案、个体可提取内容与调用成本分开设计；未声称数字分身已等同于真人。

## 8. B=MAP 和状态数量都是工作语言

“BDMIP”已确认为转录错误，统一写作 **B=MAP**。M、A、P 用于组织行为发生时的条件，并非现成的购买概率乘法公式。[S06](source-register.md#s06--福格行为模型)

早期用三项或四项状态帮助讨论某个具体问题，不代表消费者一生只需这几个状态。状态数量由要回答的问题、可用数据和比较基线决定。新案例能否复用既有规则，需要通过新情境的表现判断，不能靠统一命名宣告收敛。

**当前状态：** 保留 IPO 顶层结构与可替换的机制层，尚未获得“大一统模型”的现实证据。

## 9. 公共可见性、信息引爆与品牌选择分开

电梯媒介可能促成相互可见，数字转发与公开讨论也可能做到。投放形式本身不保证“大家都知道彼此知道”；同一楼宇有多人看到广告，也不自动形成严格意义的共同知识。

信息丰度需要区分实际知晓、对他人知晓的判断及关系分布。信息成为话题、品牌获得信任、协调行动变容易、最终购买增加，是不同结果。[S07](source-register.md#s07--复杂传播与共同知识)

用户借核物质丰度联想到“引爆”，保留为术语的灵感来源；本项目没有把核反应机制或某个物理阈值移植为广告规律。高强度广告也可能引起其他归因，目前只保留一般机制问题，不发布未经核实的具体品牌指控。

**当前状态：** ABM-001 只验证合成网络上的知晓扩散；SaaS 采购的三角色例子是协调规则推演，尚未实测采购效果。

## 10. 任务变化、TOM 和品类命名分别测量

任务权重演示改变的是“此刻更看重什么”，没有让消费者学习新事实。因此选择概率改变不必意味着品牌认知发生了变化。演示中的概率有明确候选条件，不能当作整个市场的购买率。

TOM 是给定线索下的第一提及。消费者在品类名称提示下首先说出某品牌，仍可能在真实需求中想不到这个品类。反过来，任务也可以直接唤起品牌，不必经过显式品类节点。[S11–S12](source-register.md)

**当前状态：** 拟议的场景／品类词对照只针对即时提示；未做问卷，未证明持续学习或购买迁移。

## 11. 无限算力不取消被模拟者的思考预算

模拟平台可以有充足算力，虚拟消费者仍需遵守模型中规定的时间、知识与注意范围。否则模型容易把现实中的快速判断替换成全知比较。

“候选想不全”和“全部知道但简化策略”都能成为竞争解释；两者也可能共存。Lai、Gershman 的研究提供一项可以复算的外部例证，但按键任务到品牌选择的对应关系仍需检验。[S13–S14](source-register.md)

**当前状态：** 下一步只有一个小任务——复算论文 Task 3 的时间压力对照。已找到来源，用户暂停期间不继续执行。

## 12. 什么时候才做真人研究

此前讨论给出了问卷设计和样本规划，容易让人以为必须马上发问卷。当前决定是：继续优先使用公开证据，等关键分歧无法靠已有材料解决时，再设计针对性的真人研究。

20–30 人能帮助发现题目和流程问题；效应估计需要的样本由目标差异、基准比例、误差与功效决定。已经计算的规模是特定假设下的规划值，不能用来保证所有分析都有足够把握。[S16](source-register.md#s16--真人研究样本量的规划依据)

**当前状态：** 没有问卷数据、没有招募、没有实际协作项目启动。公开论文的结果、自己的复算、自己的新样本与 Agent 生成数据，分别记录。

## 后续更新约定

新证据出现后，更新相应主张和来源，同时在这里保留旧判断为什么改变。能够恢复的旧公式保留复跑路径；缺失材料保持缺失状态，不以补写的故事代替。
